# Правила работы в этом репозитории

Владелец: Teofunk (Араик Акопян), арт-директор Клуба Алексея Козлова. Общаться по-русски, коротко и по делу.

## 1. Живой сайт kozlovclub.ru в безопасности прежде всего

- Без отдельного разрешения владельца нельзя менять тему сайта, чужие плагины, афишу (All-in-One Event Calendar), продажу билетов (Ticketscloud) и таблицы базы, кроме собственных структур плагина.
- Публикация и установка на живой сайт только после явного одобрения владельца в чате.
- Изменение, которое затрагивает живой сайт, сначала проверить на test.kozlovclub.ru.

## 2. Каждый плагин изолирован

- Свой префикс у CSS-классов, функций, опций и хуков. Никаких глобальных CSS-селекторов.
- JS без глобальных переменных и без jQuery.
- REST только в собственном пространстве имён плагина.
- Ошибка плагина не должна ломать сайт и афишу.
- В админке есть общий переключатель «Включить / Выключить».
- Установка не должна требовать обновления WordPress, темы или сторонних плагинов.

## 3. Как сдавать работу

- Работать этапами, каждый этап самостоятельная задача.
- Каждая версия плагина сдаётся ZIP-архивом и описанием: что изменилось, результаты проверок, известные ограничения.
- Статическая проверка (`php -l`, линтеры) не равна тестированию в WordPress. Так и писать, не выдавать одно за другое.
- Номер версии в заголовке плагина совпадает с тегом git `<папка>/v<версия>`.

## 4. Тексты для читателей сайта

- Не использовать длинное тире: только запятые, двоеточия, точки и скобки.
- Концерты в полночь в афише стоят на 23:59, а не на 00:00 (иначе попадают на следующий день).

## 5. Секреты и тяжёлые файлы

- Никогда не коммитить пароли, ключи API, `wp-config.php`, `.env`, дампы базы и медиатеку.
- Перед коммитом запускать `scripts/check-secrets.sh` (хук в `.githooks/pre-commit`).

## 6. Где что

- Джазета: отдельный репозиторий Teofunky/jazzeta-pipeline, у неё свои правила.
- kozlovclub.ru: WordPress, хостинг Beget, кэш W3 Total Cache, тестовая копия test.kozlovclub.ru.
