# КАРТА ЭКРАНОВ И ПОЛЬЗОВАТЕЛЬСКИХ ПОТОКОВ
## «Калибратор мышиной возни» · спецификация для Claude Design

> Загрузи этот файл в Claude Design вместе с `principles-core.md` и прототипом `.jsx`.
> Здесь описано: какие экраны есть, в каком они состоянии, что на каждом показывается из конституции, и как они соединяются. Номера §N ссылаются на разделы конституции.

---

## ЭСТЕТИКА (общая для всех экранов)

- Тёмная «приборная» тема — осциллограф / измерительный прибор.
- Фон: почти чёрный зелёно-графитовый, радиальный градиент сверху.
- Акцент: бирюзовый `#4ec9b0`. Тревога: `#e06c75`. Внимание: `#dcb67a`. Гипотеза: `#9d7cd8`.
- Шрифт: моноширинный (Courier-семейство), межбуквенный интервал в заголовках.
- Текстуры: тонкие сканлайны, лёгкое зерно. Без AI-слопа, без фиолетовых градиентов на белом.
- Бейджи доказанности — единый визуальный язык во всём продукте (см. ниже).

### Цвета бейджей (используются везде, где есть вывод)
```
ФАКТ        #4ec9b0   подтверждён источником
СВЯЗЬ       #61afef   наблюдаемая корреляция
ПАТТЕРН     #dcb67a   повторяется во времени
ГИПОТЕЗА    #9d7cd8   возможное объяснение
ПРИЧИНА     #e06c75   подтверждена отдельным анализом
СПЕКУЛЯЦИЯ  #7f8c9a   слабая идея, требует проверки
```

## ЭКРАН S0 · ВХОД / ОНБОРДИНГ (одноразовый)

**Назначение:** одним экраном объяснить суть и пустить внутрь.
**Состояния:** показывается один раз; есть «пропустить».
**Содержание:**
- Логотип-знак `⟁` + название.
- Одна фраза-манифест: «Связи существуют всегда — нет лишь наблюдателя достаточного размера».
- Три иконки-горизонта: возня (твоё) · мир (что случилось) · поиск (что назревает).
- Кнопка «Войти в калибратор».

---

## ЭКРАН S1 · ПОТОК ХАОСА (главный)

**Назначение:** пользователь сбрасывает сюда хаос и задаёт оптику.

**Состав:**
- Шапка: знак `⟁`, название, подпись «твой хаос ✕ весь интернет».
- **Селектор оптики** (§23) — ряд из 12 линз: Бизнес · Учёный · Врач · Следователь · Частный человек · Урбанист · Рынок · Редактор · Политолог · Психологический наблюдатель · Инженер · Юрист. Выбрана одна, подсвечена бирюзовым. Под рядом — строка-подсказка оптики курсивом.
- **Поле ввода потока** — крупная textarea «по строке на событие» + кнопка загрузки файла (CSV/текст).
- **Переключатель «Связать с миром»** — с подписью: «движок ищет в интернете контекст и сверяет твою возню с глобальной картиной».
- **Главная кнопка** «▶ ОТКАЛИБРОВАТЬ ВОЗНЮ» — крупная, бирюзовая, со свечением.
- Сбоку — мини-легенда уровней доказанности (6 бейджей), чтобы термины были знакомы заранее.

**Состояния экрана:**
- *пусто* — placeholder с примером, кнопка приглушена;
- *есть текст* — кнопка активна;
- *мало данных* (<15 симв.) — мягкое предупреждение под кнопкой, не ошибка.

**Куда ведёт:** кнопка → S2.

---

## ЭКРАН S2 · КАЛИБРОВКА… (процесс)

**Назначение:** показать, что система не «думает молча», а проходит честные этапы.

**Состав:**
- Центр экрана: пульсирующий знак `◖` + текущая фаза.
- **Фазы (меняются по очереди):**
  1. Извлекаю сущности из твоего хаоса…
  2. Ищу в интернете контекст по теме… *(если «Связать с миром» вкл.)*
  3. Сверяю локальные сигналы с мировыми…
  4. Отделяю общий тренд от твоей аномалии…
  5. Прогоняю гипотезы через адвоката дьявола…
  6. Проставляю уровни доказанности…
- Тонкая линия-прогресс или бегущая «осциллограмма».

**Состояния:** идёт / ошибка (красная плашка с понятным текстом и кнопкой «повторить»).
**Куда ведёт:** успех → S3; ошибка → остаётся, даёт повтор.

---

## ЭКРАН S3 · КАРТА ЗАКОНОМЕРНОСТЕЙ (результат, центральный)

**Назначение:** главный рабочий экран. Сверху — вердикт, ниже — вкладки, по краю — действия.

**Постоянная шапка результата:**
- **Вердикт** — 2–4 предложения «что здесь на самом деле происходит», в рамке с акцентной левой полосой. Это первое, что видит глаз.
- Под вердиктом — строка-сводка: «найдено: N паттернов · M аномалий · K гипотез».

**Ряд вкладок (T1–T6):**

### T1 · Локальное ✕ Мировое
Список карточек. Каждая: «ты ▸ [сигнал пользователя]» / «мир ▸ [что говорит контекст]» + ярлык-чтение (совпадает с трендом / локальная аномалия / опережает / отстаёт, цвет по смыслу) + бейдж.

### T2 · Пульс внимания (§6)
Вверху — пояснение, что поиск опережает событие. Ниже карточки: ярлык направления (▲▲ ВСПЛЕСК / ▲ РАСТЁТ / ▬ РОВНО / ▼ ГАСНЕТ, цвет по смыслу) + сам запрос «…» + что это значит + к какому сигналу относится + бейдж. Внизу — сноска о совместимости с Google Trends API.

### T3 · Паттерны и гипотезы
Три блока: «Повторяющиеся паттерны» (с бейджем и уверенностью), «Аномалии» (жёлтые плашки), «Комната гипотез» — карточки гипотез (кликабельны → S4).

### T4 · Что я не вижу (§21)
Фиолетовая панель: слепые зоны (что упускается + почему незаметно), удобные-но-ложные объяснения, вопросы, которые стоит задать.

### T5 · Что делать
Нумерованный список проверок/действий под выбранную оптику.

### T6 · Классификация входа (§14)
Визуальная разбивка: «Из N событий: шум / мусор / сигнал / ядро» — четыре столбца или дуги с числами и цветом. Клик по «отброшенным» раскрывает их (право на аудит).

**Панель 6 кнопок-действий** (закреплена сбоку или внизу):
1. Покажи скрытый порядок (пересобрать карту)
2. Что я не вижу → переход на T4
3. Разбей красивую гипотезу → S6
4. Покажи альтернативы (§16)
5. Что проверить первым → T5, отсортировано по приоритету
6. Снизь фантазию до нуля — режим «только факты и прямые связи», прячет всё ниже бейджа СВЯЗЬ

**Состояния:** на каждой вкладке возможно «пусто» — честная плашка «движок ничего не выделил под эту вкладку», не белый экран.

**Низ экрана:** строка источников из сети + кнопка «новая калибровка» → S1.

## ПАНЕЛЬ S4 · КАРТОЧКА ГИПОТЕЗЫ (модально поверх S3)

**Назначение:** полный протокол одной гипотезы (§9–10, §16).
**Состав:**
- Заголовок-утверждение + бейдж + полоса уверенности.
- Две колонки: «✓ подтверждает» / «✗ ослабляет».
- **«Что опровергнет гипотезу»** — отдельный выделенный блок (это сердце §9).
- **Альтернативные объяснения** (§16) — список конкурентов, среди них всегда «случайность/шум/ошибка данных», помечен «текущий лидер».
- **«⊕ что проверить»** — конкретное действие.
- Кнопки: «Разбей красивую гипотезу» → S6 · «Слои масштаба» → S7 · «Паспорт» → S5.

---

## ПАНЕЛЬ S5 · ПАСПОРТ ВЫВОДА (§11)

**Назначение:** провенанс — откуда взялся вывод. Раскрывается у любого вывода.
**Состав (список полей):**
- какие события использованы;
- какие источники;
- период покрытия;
- что исключено (и почему);
- метод;
- слабое место;
- уровень уверенности;
- что может изменить вывод.
**Тон:** строгий, «технический паспорт прибора».

---

## ПАНЕЛЬ S6 · АДВОКАТ ДЬЯВОЛА (§10)

**Назначение:** показать, как система пыталась разрушить собственный вывод.
**Состав:**
- Заголовок «Попытка разрушить вывод».
- Чек-лист проверок с отметками: ошибка выборки · сезонность · случайное совпадение · смена источника · альтернативная причина · слишком широкий вывод · конспирологическая связность · мало наблюдений.
- Итог: «вывод устоял» / «вывод понижен до [бейдж]» — с объяснением, что именно не выдержало.
**Визуально:** контраст с основным — будто включился скептик.

---

## ПАНЕЛЬ S7 · СЛОИ МАСШТАБА (§15)

**Назначение:** один сигнал на пяти масштабах.
**Состав:** вертикальная лестница из 5 ступеней:
- Микро — отдельное событие;
- Мезо — серия похожих;
- Макро — системная тенденция;
- Мета — изменение правил игры;
- Мир — связь с внешним фоном и пульсом внимания.
Каждая ступень — короткая строка с конкретикой по текущему сигналу. Подсветка той ступени, где сигнал реально значим.

---

## ЭКРАН S8 · НАСТРОЙКИ ИСТОЧНИКОВ (права пользователя §22)

**Назначение:** сделать систему управляемой, не страшной.
**Состав — список источников/событий с контролами на каждом:**
- удалить из анализа;
- понизить вес;
- пометка надёжности.
**Глобальные тумблеры:**
- режим строгой проверки;
- запретить спекуляции;
- только факты;
- показать отброшенные данные;
- экспортировать карту связей;
- очистить память анализа.

---

## ВСПЛЫВАЮЩЕЕ S9 · КРАСНЫЕ ФЛАГИ (§20)

**Назначение:** предупреждать о риске ложного смысла прямо в выдаче.
**Поведение:** не отдельный экран, а плашка-предупреждение вверху S3, когда сработал риск.
**Текст-флаги (показываются релевантные):** мало данных · короткий период · нет контрольной группы · смешаны типы событий · сменился способ сбора · ненадёжный источник · вероятна сезонность · медийный шум · наводящий вопрос · вывод слишком широк.
**Вид:** янтарная плашка, иконка ⚠, сворачиваемая.

## ТРИ ПОЛЬЗОВАТЕЛЬСКИХ ПОТОКА (сценарии для проверки дизайна)

### Поток A — «Быстрый взгляд» (массовый путь)
S1 (вставил события, оптика «бизнес», «связать с миром» вкл.) → S2 → S3 (читает вердикт + T1) → жмёт «Что я не вижу» → T4 → доволен, «новая калибровка».
*Дизайн обязан:* сделать вердикт и T1 самодостаточными за 10 секунд чтения.

### Поток B — «Дисциплина доказательства» (профи: учёный/следователь)
S1 → S3 → T3 открывает карточку гипотезы S4 → читает «что опровергнет» → жмёт «Разбей гипотезу» S6 → видит, что вывод понижен → открывает Паспорт S5 → проверяет источники.
*Дизайн обязан:* сделать переходы S4↔S5↔S6 быстрыми, без потери контекста (модальные слои, не новые страницы).

### Поток C — «Управление и доверие» (осторожный пользователь)
S1 → S3 → видит S9 красный флаг «вероятна сезонность» → идёт в S8 → понижает вес шумного источника + включает «только факты» → «Покажи скрытый порядок» (пересборка) → карта чище.
*Дизайн обязан:* сделать так, чтобы действие в S8 заметно меняло результат на S3 — пользователь должен чувствовать управление.

## ПРИОРИТЕТ ЭКРАНОВ ДЛЯ DESIGN (что делать первым)

1. **S1, S2, S3** — без них продукта нет. Сначала довести их.
2. **S4, S5, S6** — то, что отличает нас от «обычного AI». Делать вторыми.
3. **T6, S7, S8, S9** — глубина и доверие. Третья волна.
4. **S0** — последним; онбординг легко добавить, когда всё остальное ясно.

## ЕДИНЫЕ ПРАВИЛА ДЛЯ ВСЕХ ЭКРАНОВ

- Бейдж доказанности виден везде, где есть вывод. Нет вывода без бейджа.
- У любого вывода можно открыть Паспорт (S5).
- Состояние «пусто» всегда честное и объяснённое, никогда не белый экран.
- Ошибки — человеческим языком + действие «повторить».
- Эпистемология видима: возможность опровергнуть и проверить должна читаться глазами, а не прятаться в меню.
