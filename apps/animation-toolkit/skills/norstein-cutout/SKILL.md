# Перекладка по Норштейну из одной картины

Удачный образец: «Три индианки», 16 с, 1080p (код: animation-toolkit/norstein/, порядок zoom → cut → build → render → layout). Пользователь: «шикарно». Неудачный: сова в полёте с автоматической нарезкой (NEGATIVE_owl_rig_autocut.py), пользователь: «очень плохо вырезал».

## Почему сова не вышла (не повторять)
- Силуэт выделял алгоритм: перья по тону как небо, в деталь попала бахрома неба, кончики перьев пропали.
- Линии разреза шли прямыми отрезками по сетке, а не по рисунку: квадратная голова, крыло рассечено поперёк перьев.
- Нахлёст делался раздуванием детали, и в запас попали чужие пиксели (глаз, кусок спины): в движении вылезла ступенька.
- Небо за птицей пришлось выдумывать широкой заплаткой, на взмахе она открывалась.

## 1. Нарезка вручную (cut.py)
1. `zoom.py`: кропы ×2-3 с делениями каждые 10 px и подписями каждые 50 px. Посмотреть каждый.
2. Обвести каждую деталь точками по нарисованному краю (волосы, плечи, серьги, рыба), сгладить кривой Catmull-Rom.
3. Привязать край к рисунку: GrabCut только в узкой полосе (наружу 7-10 px, внутрь 10-14 px). Там, где разрез проходит сквозь фигуру (шея, воротник), оставить ручную линию (keep_bottom). Оставить крупнейшую компоненту, залить мелкие дыры.
4. Мягкий край только по небу (guidedFilter r=3, eps=1e-3); где деталь лежит на другой детали, край жёсткий (σ 0.7), иначе виден шов.
5. Резать по анатомии: голова по воротнику и концам волос, серьги отдельно, хвост рыбы по стеблю. Тонкие плавники брать только штрихами (маска тёмных линий), без неба между лучами.
6. Отдельные пряди не вырезать: под ними пришлось бы дорисовывать волосы. Пряди гнуть внутри детали головы картой веса (0 на лице, растёт к концам).

## 2. Подложки и нахлёст (build.py)
- Под нижним краем головы в слое тела оставить саму картину: сдвиг на 1-2 px не даёт шва.
- Небо за фигурами: заполнять только внутри расширенной маски объектов, вне её оставить оригинал. Сдвиг полос той же строки годится только в верхних строках с гравированными линиями; ниже мягкая дымка (нормированное размытие двух масштабов) плюс зерно случайными патчами. Сдвиг полос везде дал полосы; FSR-inpaint дал мазню.
- Травы переднего плана: маска = светлее локальной медианы и низкая насыщенность, ниже голов. Цвет травы «развязать»: plant = (P - (1-a)·under) / a.
- Платье под травами: низкие частоты только по насыщенным пикселям платья (C > 22, L < 68) плюс зерно платья.
- Под серьгами в голове: волосы из окружения (не лицо).
- **Контроль**: собрать кадр без движения и сравнить с картиной. Цель: средняя разница меньше 4 из 255; смотреть карту разницы, швов быть не должно.

## 3. Риг (render.py)
- Якорь в суставе: голова у основания шеи, серьга у мочки, хвост рыбы на стебле, тело рыбы в центре.
- Иерархия: Figures (нуль) → Body, Head_*; серьги → Head_Left; Fish_Big (нуль) → Fish_Body → Fish_Tail. Голова привязана к нулю, а не к телу, чтобы отставать от дыхания.
- Движение (амплитуды в px картины 1024): дыхание у каждой своё, период 4.6 с с разной фазой, подъём 1.1; наклон головы 0.6° за 7.3 с; голова отстаёт на 2 кадра; пряди 2 px; серьга ±4° с отставанием 3 кадра и против наклона головы; рыба 2 px/с, хвост 10° с частотой 1.2 Гц; травы до 3.2 px, амплитуда растёт с высотой.
- **На двойках**: марионетка считает время как (i//2)*2/24; камера и туман идут на единицах.

## 4. Станок (6 ярусов)
Коэффициенты наезда: небо 0.55 (размытие 0.8 px), калька 1 0.65 (плывёт влево 5 px/с, до 22%), рыбы 0.7, фигуры 1.0 (фокус), калька 2 1.15 (вправо 7 px/с, до 12%), травы 1.3 (размытие 1.5 px). Поверх всего дымка 5%, тень облака 9% только на фигурах и травах, проход слева направо за весь план. Виньетка 10%. Наезд 960 → 900 px ширины картины за 16 с. Текстуры увеличены ESPCN x2, кадр 1920×1080.

## 5. Чего нельзя из одной картины
Моргание, поворот головы, шаг бизона, взмах крыла с изменением формы. Нужны дорисованные фазы (3-4 рисунка): Midjourney Vary Region (Editor) на оригинале, выделить только глаза, голову или крыло. Промпты, например: «the same face, upper eyelids lowered halfway over the irises, calm, drawn with the same thin dark line, same encaustic plaster texture and colors, nothing else changes --ar 1:1 --profile ov5fu5»; «the same face, eyes gently closed ...». Моргание: открыты, полуприкрыты, закрыты, полуприкрыты, на двойках, у каждой в своё время раз в 4-7 с. Пока фаз нет, не имитировать их поворотом.
