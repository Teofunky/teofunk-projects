# painted-cutout: перекладка и оживление для живописи (фильм «Дурак на холме», 25.11.2026)

Кадр в пропорциях картины (1080×1502 для листа 912×1268), 24 к/с.

- `film2.py`: PSheet (лист и заплатки `fill`, `fill2`), Sprite (фигура с заплаткой под ней), PScene (вид камеры, поля смещения, рендер),
  поля `wind`, `ripple`, `gaze`, `blinkfield` (моргание сжатием к линии ресниц), `smile`, `rotfield`, `shiftfield`, `pulse`, титр.
- `crowgen.py`: ворона, нарисованная кодом. Крыло на скелете (плечо, кисть, пять маховых «пальцев»), взмах вниз 56 % цикла,
  на подъёме кисть складывается и уходит назад, 3,4–4,4 Гц, ракурс по направлению полёта, посадка с раскрытыми крыльями. Фактура и цвет с ворон картины.
- `fscenes.py`: 15 сцен фильма, `frun.py s1 s2 ...` рендерит их.

Выученное: из одной нарисованной позы птицы полёт не собрать (сплющивание и изгиб крыла выглядят ужасно); ветер в плаще давать только в край и подол.
Картины в репозиторий не кладутся.
