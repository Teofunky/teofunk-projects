# SmartFind: умный поиск по Mac

Пишешь как человеку («фотка с гитарой на сцене прошлой осенью», «чем смонтировать видео», «договор с артистом за октябрь»), Claude разбирает запрос, Spotlight ищет, Claude сортирует найденное.

## Установка (один раз)

1. Открой Терминал и выполни:
   `bash ~/Documents/teofunk-projects/apps/smartfind/install.sh`
   (скрипт копирует программу в ~/Library/Application Support/SmartFind, так что папку репозитория потом можно двигать)
2. Открой SmartFind: ⌘Пробел → SmartFind.
3. При первом запуске вставь ключ Claude API (Claude Console → API Keys). Ключ хранится в Связке ключей macOS.
4. macOS спросит доступ к папкам (Документы, Рабочий стол, Загрузки): разреши.

## Горячая клавиша

Приложение «Быстрые команды» → новая команда → действие «Открыть приложение» → SmartFind → в настройках команды «Добавить сочетание клавиш» (например ⌃⌥Пробел). Повторный вызов поднимает уже открытое окно.

## Управление

- Enter: искать; повторный Enter открывает выбранный файл
- ⌘Enter: показать в Finder
- ↑↓: выбор, Esc: очистить
- Двойной щелчок: открыть

## Как ищет

- Имена файлов (рус., англ., транслит), текст внутри документов, даты, тип, размер.
- Что на фото: метки, которые macOS сама ставит картинкам (с Ventura). Классификатор ошибается, поэтому Claude ещё раз проверяет порядок.
- Приложения: Claude выбирает подходящие по смыслу из установленных.
- Пока НЕ ищет внутри медиатеки «Фото» (следующий этап).

## Уборка

В той же строке: «разбери загрузки и рабочий стол», «что занимает больше всего места», «найди дубли фоток», «убери установщики и мусор».

- **Разложить по папкам:** Claude предлагает, куда положить каждый файл из Загрузок и Рабочего стола (или из папки, которую назовёшь) по твоей структуре Documents. Папку можно поменять в каждой строке.
- **Большие файлы:** всё крупнее 200 МБ (или сколько скажешь) с датой последнего открытия. Отмечены только давно не открытые установщики и архивы.
- **Дубликаты:** побайтовое сравнение (хеш), в группе оставляется файл из папок 01-09 и без «копия» в имени.
- **Мусор:** установщики .dmg/.pkg, недокачанные файлы, скриншоты старше 2 месяцев (их не отмечает).

Безопасность:
- Ничего не удаляется. Цель «_На удаление» = папка `Documents/_На удаление/SmartFind <дата время>/` с сохранением исходных путей.
- Кнопка «Переместить» срабатывает со второго нажатия.
- После уборки кнопка «Отменить»; на стартовом экране «Отменить последнюю уборку». Журналы: `~/Library/Application Support/SmartFind/journal/`.
- Не трогает: ~/Library, медиатеки (Фото, Музыка, Final Cut, Logic), содержимое программ и пакетов, папки программ в корне Documents (Adobe, Codex, Max 9, REAPER Media, Magenta, MRT2 Bundle, Guitar, Metronome, KonnakolMaster, reel_practice_mac_v2). Список меняется в `config.json`: `{"protected": [...]}`.

## Файлы

- Программа и лог: `~/Library/Application Support/SmartFind/` (лог поиска: `smartfind.log`)
- Сменить модель: создать там `config.json` с `{"model": "claude-haiku-5-5"}`
- Ограничить папки поиска: `{"roots": ["/Users/имя/Documents"]}`

## Удаление

```
rm -rf ~/Applications/SmartFind.app ~/Library/Application\ Support/SmartFind
security delete-generic-password -s "SmartFind Anthropic API"
```
