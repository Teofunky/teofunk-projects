# Нейрожурналист

Отдельное веб-приложение для «Ежедневной Джазеты»: музыкант входит по личной ссылке, нейросеть собирает о нём досье и берёт глубокое интервью. Готовый текст после согласования с героем уходит черновиком в Пульт газеты, публикует редактор. В тексте честная пометка, что интервью вела нейросеть.

## Этапы

| Этап | Что | Статус |
|---|---|---|
| 1 | Банк вопросов из лучших интервью | идёт: v0.3 в [`bank/`](bank), 83 приёма и 237 вопросов; правила в [`principles.md`](principles.md) |
| 2 | Пробное интервью прямо в чате | проба с Илугдиным остановлена на 7-м ходу, разбор в [`pilot/ilugdin/log.md`](pilot/ilugdin/log.md) |
| 3 | Веб-приложение (Claude API) | идёт: 3.1 ядро интервьюера в [`engine/`](engine) |
| 4 | Тип «большой текст» в плагине Джазеты (репозиторий jazzeta-pipeline) | не начат |

Решения, которые ещё за редактором, собраны в конце [`principles.md`](principles.md).
