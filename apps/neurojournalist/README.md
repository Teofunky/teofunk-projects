# Нейрожурналист

Отдельное веб-приложение для «Ежедневной Джазеты»: музыкант входит по личной ссылке, нейросеть собирает о нём досье и берёт глубокое интервью. Готовый текст после согласования с героем уходит черновиком в Пульт газеты, публикует редактор. В тексте честная пометка, что интервью вела нейросеть.

## Этапы

| Этап | Что | Статус |
|---|---|---|
| 1 | Банк вопросов из лучших интервью | идёт: пилот v0.1 в [`bank/`](bank) |
| 2 | Пробное интервью прямо в чате | не начат |
| 3 | Веб-приложение (Claude API) | не начат |
| 4 | Тип «большой текст» в плагине Джазеты (репозиторий jazzeta-pipeline) | не начат |

Решения, которые ещё за редактором: число реплик (в ТЗ 28–35), формулировки блока о нейроискусстве, постоянный финальный вопрос рубрики.
