# Ядро интервьюера (этап 3.1)

Интервью в терминале через Claude API. Программа берёт досье, план, `principles.md` и банк (`bank/`) и после каждого ответа просит Claude заполнить журнал решения и задать ровно один следующий вопрос (инструмент `next_turn`). Веб-интерфейса пока нет: это ядро, которое потом встанет за чатом.

## Запуск на Mac

```bash
cd ~/Documents/teofunk-projects && git pull
cd apps/neurojournalist/engine
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # ключ вашей организации в Anthropic, в репозиторий не класть
python3 interviewer.py --dossier ../pilot/ilugdin/dossier.md --plan ../pilot/ilugdin/plan.md
```

- Ответ вводится одной строкой, Enter отправляет.
- `стоп` завершает интервью; Ctrl+D или Ctrl+C сохраняет сессию без завершения.
- Продолжить: `python3 interviewer.py --resume ../pilot/ilugdin/sessions/<папка>`.
- Модель по умолчанию `claude-opus-5-5`; дешевле: `NJ_MODEL=claude-sonnet-5-5 python3 interviewer.py ...`.
- Проверка без API: добавить `--dry-run`.

## Интервью через Telegram-бота

Бот работает на вашем Mac и сам опрашивает Telegram: сервер и туннель не нужны. Герой входит по личной ссылке и отвечает текстом или голосовыми. Голосовые расшифровывает OpenAI (`gpt-4o-transcribe`, при ошибке `whisper-1`), Claude API вызывается с вашего Mac.

1. **Создать бота:** в Telegram открыть @BotFather, команда `/newbot`, имя например «Джазета: интервью», адрес например `jazzeta_interview_bot`. BotFather пришлёт токен.
2. **Запустить на Mac** (после шагов установки выше):

```bash
export ANTHROPIC_API_KEY=...
export TELEGRAM_BOT_TOKEN=...      # токен от BotFather
export OPENAI_API_KEY=...          # для голосовых
caffeinate -i python3 bot.py --dossier ../pilot/ilugdin/dossier.md --plan ../pilot/ilugdin/plan.md
```

3. Программа напечатает две ссылки: **для героя** и **для наблюдателя**. Свою откройте сами: туда будут приходить вопросы и ответы. Ссылку героя отправьте ему.
4. **Сначала проверьте на себе в отдельной сессии:** `--out /tmp/nj-test`, откройте ссылку героя этой сессии сами и ответьте на 2–3 вопроса. Ссылка героя привязывается к первому, кто по ней зашёл, поэтому для Дмитрия запустите новую сессию без `--out`.

Как ведёт себя бот:
- ждёт 40 секунд тишины после последнего сообщения и только потом задаёт следующий вопрос (`--quiet 60`, если голосовые длинные);
- «стоп» завершает сразу; сообщения, написанные, пока готовился вопрос, добавляются к прошлому ответу;
- чужим отвечает, что это личный бот редакции;
- если Claude API не ответил, повторяет через минуту; если не удалась расшифровка, просит повторить голосовое;
- Mac должен быть включён, крышка открыта или подключено питание, терминал открыт. `caffeinate -i` не даёт Mac уснуть. После перезапуска: `--resume <папка сессии>`, ссылки остаются прежними.

## Что сохраняется

Папка сессии (по умолчанию `pilot/<герой>/sessions/<дата-время>/`):
- `session.json`: источник, всё остальное строится из него;
- `transcript.md`: дословная расшифровка;
- `log.md`: журнал решений по каждому ходу, с расходом токенов.

Папки `sessions/` не попадают в git (`.gitignore`): в них личные ответы героев.

## Как устроено

- Системный промпт: `prompts/interviewer_system.md` плюс принципы, досье, план и весь банк в компактном виде (около 57 тысяч символов). Большой блок помечен для кеширования: с первого хода за него платим по цене кеша. Кеш живёт несколько минут; если герой отвечает медленнее, кеш пересоздаётся, и ход стоит дороже.
- Каждый ход: расшифровка целиком плюс подсказки (сколько коротких ответов подряд, номер хода, «стоп»).
- Правила из пробного интервью: после двух ответов короче 8 слов вопрос должен допускать ответ названием, местом, моментом или именем; третий абстрактный вопрос подряд запрещён.
- Длинное тире в вопросе заменяется запятой с пометкой в журнале.

## Проверки

- `python3 test_interviewer.py`: 5 тестов без API (сборка контекста, короткие ответы, «стоп», запись файлов, продолжение сессии). Проходят.
- `python3 test_bot.py`: 6 тестов бота на подставных Telegram, Claude и расшифровке (доступ по ссылке, окно тишины, голосовые, позднее дополнение, «стоп», сбой API). Проходят. Отдельно проверено, что запрос на расшифровку к OpenAI собирается правильно.
- **С настоящими Claude API, Telegram и OpenAI программы не запускались**: в рабочей среде Claude нет ключей. Первый настоящий запуск делаете вы.

## Ограничения

- В терминале только текст; голосовые принимает бот.
- Telegram в России работает с перебоями; если у Дмитрия бот не открывается, запасной вариант: вы пересылаете вопросы и ответы через терминальную версию.
- Досье пишется вручную (сборщик досье: задача 3.2).
- По моим данным, Россия не входит в список регионов, где доступен Claude API, поэтому из Москвы вызов может не пройти. Я это не проверял; из Еревана должно работать.
