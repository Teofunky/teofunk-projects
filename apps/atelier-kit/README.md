# atelier-kit

Набор, с которым Claude оживляет картину в ATELIER Studio без ручной разметки в студии:
картина и одна фраза на входе, проект `.atelier2` и MP4 на выходе. Рендерит сам ATELIER
(его автономный HTML в headless Chrome), поэтому кадр совпадает с тем, что видно в студии на Mac.

Проверено на ATELIER 0.4 (ноябрь 2026), картина «Девочка с рыбами».

## Что нужно

- Python 3.10+, `pip install playwright opencv-python pillow numpy --break-system-packages`, Google Chrome.
- `ATELIER-Studio.html` из папки ATELIER на Mac (`~/Desktop/ATELIER-Studio-Mac (2)/`).
  Путь задаётся переменной `ATELIER_HTML` (по умолчанию `/home/claude/atl/ATELIER-Studio.html`).

## Конвейер

| Шаг | Команда | Что даёт |
|---|---|---|
| 1. Сетка | `mark.py grid картина.png g.jpg` | картина с координатами, чтобы снимать точки |
| 2. Крупно | `mark.py zoom картина.png eye.jpg x0 y0 x1 y1 --step 5 --scale 8` | глаз, хвост, плавник с сеткой в пикселях |
| 3. Объект | `mark.py segment картина.png x0 y0 x1 y1 [--bias 0.7]` | контур фигуры (цвет против фона по краю рамки) |
| 4. Ярус и подложка | `mark.cutout(...)`, `mark.plate(...)`, `mark.merge(...)` | вырезка на холсте картины и чистая подложка под ней |
| 5. Описание | `spec.json` (формат ниже) | что двигается, где, когда |
| 6. Проверка разметки | `mark.py overlay картина.png spec.json o.jpg` | все маски, опоры и цели взгляда поверх картины |
| 7. Сборка | `project.py spec.json проект.atelier2` | проект для студии |
| 8. Подбор | `variants.py spec.json blink '{"A":{...},"B":{...}}' --frames 20,34 --box ... --solo` | варианты одной партии рядом, крупно |
| 9. Автопроверка | `qa.py проект.atelier2 --painting картина.png --out qa/` | отчёт и картинки (ниже) |
| 10. Фильм | `render.py проект.atelier2 --movie фильм.mp4 --height 1080` | MP4 штатным экспортом ATELIER |
| Обратно | `unpack.py проект.atelier2 папка --painting картина.png` | проект, поправленный в студии, снова в `spec.json` |

Скорость (2 CPU): 10 с фильма в 1080p считаются около 45 с, автопроверка около 25 с.

## Что проверяет qa.py

1. **Тождество.** Партии выключены, ярусы и камера на месте: кадр должен совпасть с картиной.
   Ловит швы вырезок и ободки. Норма: средняя разница меньше 0,1, максимум единицы.
2. **Вне масок.** Камера остановлена, кадры по всему плану: вне партий и ярусов картина не меняется
   ни на один уровень (`outside_masks.jpg`, разрешённые зоны обведены).
3. **Моргания.** На пике под веко ушло не меньше 80 % тёмных пикселей радужки и зрачка.
   Цвет века смотреть глазами на `blink_*.jpg`.
4. **Жизнь.** Все кадры в малом размере: застывшие участки дольше 1,5 с, карта движения
   без камеры (`motion_map.jpg`), контактный лист 1 кадр/с.

Итог в `report.txt` и `report.json`. Код выхода 1, если есть замечания.

## spec.json

Координаты в пикселях исходной картины, время в секундах (акценты) или кадрах (attack, release, hold).

```json
{
 "name": "Девочка с рыбами",
 "painting": "devochka-s-rybami.png",
 "plate": "plate.png",
 "ratio": "auto",
 "seconds": 10,
 "exposure": 2,
 "audio": {"file": "грув.mp3", "bpm": 96, "zero": 0.0},
 "notes": "сценарий плана, его видно в студии",
 "parts": [
  {"id": "blink", "effect": "blink", "shape": {"ellipse": [775, 214.5, 15, 10.5]}, "feather": 2, "accents": [1.4, 4.9, 8.1]},
  {"id": "gaze", "effect": "gaze", "shape": {"poly": [[764,220],[779,211],[789,217],[780,225]]},
   "target": [915, 105], "accents": [5.5], "attack": 18, "release": 30, "hold": 60},
  {"id": "tail", "effect": "hinge", "shape": {"poly": [[1220,76],[1372,36],[1386,178],[1220,168]]},
   "pivot": [1225, 120], "period": 2.4, "host": "fish-rtr"}
 ],
 "tiers": [
  {"id": "fish-rtr", "name": "Красная рыба", "image": "L_rtr.png", "pivot": [1140, 110], "depth": 0.2,
   "keys": [{"t": 0, "dx": 0}, {"t": 5, "dx": -9, "dy": 0}, {"t": 10, "dx": -18}]}
 ],
 "camera": {"keys": [{"t": 0, "zoom": 1}, {"t": 10, "zoom": 1.05}]}
}
```

- `ratio`: `auto` берёт ближайшее к картине из 16:9, 9:16, 1:1, 2:3, 3:2, 4:3, 4:5 (картина вписывается целиком).
- `shape`: `ellipse [cx, cy, rx, ry, (угол)]`, `rect [x0, y0, x1, y1]` или `poly [[x, y], ...]`.
- `accents` в секундах или `frames` в кадрах; без них партия должна быть `"mode": "loop"`.
- `tiers`: ярусы станка. `image` на холсте картины (тот же размер, прозрачность вокруг фигуры),
  `keys` с `t`, `dx`, `dy` (пиксели), `angle` (градусы), `scale`; `parent` для иерархии (корпус → голова);
  `phases` для сменных рисунков `[{"t": 0, "image": ...}, {"t": 1.5, "image": ...}]`.
- `camera`: те же ключи, `zoom` вместо `scale`. По умолчанию камера стоит.
- `host` у партии: партия живёт на ярусе и едет вместе с ним.
- Любое поле партии из ATELIER можно задать прямо: `amp`, `feather`, `period`, `phase`, `angle`, `ease`, `link`, `follow`.

## Эффекты ATELIER 0.4

| effect | Что делает | Главное |
|---|---|---|
| `blink` | веко закрывает глаз, цвет берёт с кожи над маской | верх эллипса на складке века, `feather` 2–3 |
| `gaze` | зрачок смещается к `target` | маска по радужке, `hold` держит взгляд |
| `brow`, `smile` | брови и щёки вверх, уголки рта | акценты |
| `flex` | свободный изгиб от `pivot` к `target` | волосы, подол, ткань; `amp` 3–8 |
| `hinge` | поворот вокруг `pivot` на `angle` | хвосты, руки, ветки; петля `period` |
| `wing` | взмах с чистой подложкой | `plate` для своей подложки |
| `strike` | удар и отскок | `tip`, `rigid`, `target` обязательны |
| `shift` | сдвиг области | мелкие подвижки |
| `wind` | порывы по горизонтали, сильнее у верха маски | трава, кроны |
| `wave` | рябь по строкам | вода |
| `light` | яркость пульсирует | луна, звёзды, окна |
| `donor` | в маску вставляется видео (`video`) | например дубль Seedance только в небо |

## Правила, которые уже выучены

- **Моргание.** Эффект красит веко строкой кожи над маской. Тесная маска по ресницам даёт оливковое
  веко (снятое с тени складки). Верх эллипса ставить на складку века, по бокам на 2 px шире глаза,
  `feather` 2. Подбирать через `variants.py` по кадрам до акцента и на пике.
- **Вырезка яруса.** `cutout(grow=2)` и `plate(grow=2)` с одинаковым запасом: тогда в покое сборка
  совпадает с картиной (тождество 0,03), а при движении нет ободка. Тонкие тёмные плавники `segment`
  может потерять: дорисовать контур по `zoom` и склеить `merge`.
- **Подложка** на больших дырах размазывается (Telea). Её всегда смотреть глазами; фигуру двигать
  недалеко, чтобы заплатка оставалась под ней.
- **Камера** по умолчанию стоит (правила Teofunk в скилле painting-film).
- ATELIER не дорисовывает: поворот головы, шаг, уход фигуры за кадр требуют фаз или видеодубля в маску.
