# Девочка с раковиной (23.11.2026)

12 с, 1080p, 17 ярусов, 24 партии. Рыбки плывут, море волнуется, девочка переступает с ноги на ногу,
замахивается и бросает раковину к солнцу; круги на воде, рыбы шарахаются. Картина на Mac:
`ATELIER-Studio-Mac (2)/Картины/Девочка с раковиной.png`.

Порядок: `fish3.py` (мягкие маски рыбок, `mark.matte`), `girl3.py` (девочка: `mark.refine` по контурам
из `girl_polys.json`, волосы `mark.matte`), `plate.py` (ярусы и подложка: рыбы Telea, девочка по строкам,
под рукой перенос соседнего неба), `gen_spec.py` (ключи: шаги, замах, бросок по кривой Безье, испуг рыб)
→ `ripples.py` (круги на воде фазами яруса) → `gen_spec.py` ещё раз → `project.py`.

Проверка: вне масок 0 пикс., застывших нет, тождество средняя 0,25 (мягкие края рыб и волос).
