=== Kozlov Perf ===
Version: 1.0.0
Requires: WordPress 6.0+, PHP 7.4+

Изолированный плагин оптимизации загрузки kozlovclub.ru.
Не меняет файлы темы, базу, афишу и другие плагины. Работает только на фронте,
только с готовым HTML и очередью скриптов. Любая ошибка внутри плагина
возвращает страницу без изменений.

== Что делает (всё включается/выключается в Настройки → Kozlov Perf) ==

1. Нативная ленивая загрузка. Разметка a3 Lazy Load (заглушка + data-src)
   возвращается к обычной, его JS/CSS не грузятся. Первые N картинок страницы
   (по умолчанию 8: логотип, слайдер, первый ряд афиши) грузятся сразу,
   остальным ставится loading="lazy" decoding="async".
2. Easy FancyBox и YouTube Embed Plus убираются со страниц, где они не нужны.
   Решение по готовому HTML: FancyBox остаётся при ссылках с классом fancybox
   или прямых ссылках на картинки; YouTube Embed Plus остаётся, если есть
   его embed (классы __youtube_prefs__/epyt-) или шорткод [embedyt].
3. Список скриптов, которые не подключать (по умолчанию jquery.animateNumber,
   в теме его вызов закомментирован). jQuery в этот список попасть не может.
4. defer для скриптов из списка (по умолчанию wpglobus). jQuery и скрипты с
   inline-хвостом -js-after не трогаются.
5. Отключение wp-emoji.
6. Preconnect к fonts.googleapis.com, fonts.gstatic.com, mc.yandex.ru,
   top-fwz1.mail.ru, ticketscloud.com.
7. Чистка head: RSD, wlwmanifest, shortlink, meta generator, заголовок
   X-Powered-By.
8. Исправление задвоенного параметра ver в адресах (…?ver=X&ver=X).
9. Дубли: одинаковые <script src> и <link rel=stylesheet>, дубли Open Graph
   (og:url/title/type/description/locale/site_name: остаётся первый непустой;
   og:image: убираются точные повторы).
10. CSS блоков Гутенберга: выключено по умолчанию, включать после проверки.

== Установка ==

1. Плагины → Добавить новый → Загрузить плагин → kozlov-perf.zip → Установить → Активировать.
2. Настройки → Kozlov Perf: ничего менять не нужно, настройки по умолчанию безопасные.
3. Рекомендуется деактивировать a3 Lazy Load (плагин его заменяет). Можно и не
   деактивировать: его разметка всё равно возвращается к обычной, а скрипты не грузятся.

== Проверка ==

- Открыть главную и страницу концерта: картинки на месте, слайдер крутится,
  видео играет, кнопки Ticketscloud работают, поиск и фильтры афиши работают.
- В исходном коде страницы перед </body> есть комментарий
  <!-- Kozlov Perf 1.0.0: … --> с тем, что было сделано.
- Любая страница с ?kperf=off показывается без оптимизаций (для сравнения).
- Если используется кеш-плагин: после активации сбросить кеш.

== Откат ==

Снять галочку «Плагин включён» или деактивировать плагин. Файлы темы и
другие плагины не затронуты, откатывать нечего.
