=== Kozlov New Year ===
Requires at least: 5.6
Requires PHP: 7.2
Stable tag: 1.0.0

Новогодняя страница «Новый год в Клубе Алексея Козлова» с редактором.

== Установка ==
1. Плагины → Добавить новый → Загрузить плагин → kozlov-new-year.zip → Установить → Активировать.
2. Плагин сам создаст черновик страницы /novyj-god/ (на сайте она не видна) и попробует найти номер Яндекс Метрики в теме.
3. Слева в меню появится «Новый год». Проверьте вкладку «Настройки» (номер Метрики), нажмите «Посмотреть черновик».
4. Всё в порядке: кнопка «Опубликовать» вверху редактора.

== Что не трогает ==
Файлы темы, таблицы базы, афишу, другие страницы и плагины. Данные лежат в трёх опциях: kny_data, kny_history, kny_settings.
Выключить страницу без удаления: «Новый год» → Настройки → снять «Показывать новогодний дизайн».
Удаление плагина стирает только его опции; сама страница WordPress остаётся.
