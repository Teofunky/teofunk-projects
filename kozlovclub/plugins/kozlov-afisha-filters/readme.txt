=== Kozlov Afisha Filters ===
Requires at least: 5.3
Requires PHP: 7.2
Stable tag: 1.0.1
License: GPL-2.0-or-later

Панель фильтров афиши на главной странице kozlovclub.ru: Сегодня, Завтра, Выходные, Дата, Цена, Жанр, Сцена и поиск «Артист или концерт».

== Что делает ==

* Ставит панель сразу под слайдером главной страницы.
* Концерты берёт из индекса Kozlov Smart Search (нужна версия 1.0.4 или новее: в её индексе есть время окончания концертов).
* При выбранном фильтре прячет лишние карточки афиши темы. Видны те же карточки темы: с фото, кнопками «Купить билет» и виджетом Ticketscloud.
* Над карточками показывает заголовок по выбранным датам («Концерты сегодня, 17 октября», «Концерты 20–25 октября»), число концертов и кнопку «Сбросить фильтры».
* Выбор сохраняется в адресе страницы (параметры kaf_when, kaf_from, kaf_to, kaf_price, kaf_entry, kaf_genre, kaf_stage, kaf_q): ссылку можно отправить.
* Поиск понимает опечатки, названия и адреса сцен («Мясницкая», «Маросейка», «Мансарда»), жанры.
* На телефоне кнопки стоят в две строки, окна открываются шторкой снизу. Есть управление с клавиатуры: Tab, Esc, возврат фокуса на кнопку.
* Без выбранных фильтров афиша выглядит как без плагина, переключатель «списком / плиткой» темы остаётся родным.

== Безопасность ==

* Тема, события, страницы и таблицы календаря не меняются. Своих запросов к базе на сайте нет. Запись плагина: настройка kaf_settings.
* Плагин сбрасывает кэш страниц W3 Total Cache при включении и выключении режима «для всех» и при выключении плагина. В ответ индекса Kozlov Smart Search он добавляет поле kaf с режимом панели.
* Стили панели живут в Shadow DOM и не действуют на страницу. Скрипт не создаёт глобальных переменных и не использует jQuery.
* Карточки прячутся только через style="display:none". При сбросе атрибут style возвращается слово в слово.
* Карточка сопоставляется с концертом по ссылке, полной дате и времени. Если карточки на странице и данные индекса расходятся, фильтры отключаются, видна вся афиша и кнопка «Обновить страницу».
* Если индекс не загрузился, поиск выключен (ответ 403), панель выключена в настройках, разметка темы изменилась или в коде панели случилась ошибка, панель убирает себя. В уже открытых вкладках это происходит при фоновой проверке раз в 5 минут.
* Раз в минуту панель пересчитывает фильтры по времени: смена суток, закончившиеся концерты.
* Концерт, который уже начался, под фильтрами не показывается: его нет в индексе поиска, как и в афише темы после обновления страницы.
* Это проверено на моделях страницы и на настоящей главной в Chrome. Сторонние скрипты и браузеры, которые меняют разметку афиши иначе, отдельно не проверялись.
* Скрипт подключается только на главной странице и только тем, кому разрешён режим.

== Режимы ==

* Выключена: на сайте ничего нет.
* Проверка: панель видит только вошедший администратор.
* Включена для всех.

При включении и выключении режима «Включена для всех» плагин сам сбрасывает кэш страниц W3 Total Cache. Если кэш другой, его нужно сбросить вручную.

== Установка ==

1. Плагины → Добавить новый → Загрузить плагин → kozlov-afisha-filters-1.0.1.zip → Установить → Активировать.
2. Настройки → Kozlov Afisha Filters → режим «Проверка» → Сохранить.
3. Откройте главную страницу в этом же браузере и проверьте панель.
4. Режим «Включена для всех» → Сохранить.

== Аварийное отключение ==

* Настройки → Kozlov Afisha Filters → «Выключена».
* Без админки: строка define( 'KAF_DISABLE', true ); в wp-config.php или удаление папки wp-content/plugins/kozlov-afisha-filters, затем сброс кэша страниц (Performance → Purge All Caches).

== Исходный код ==

Папка src: kaf-app.js и kaf.css. Файл assets/kaf-app.js собран из них: стили вставлены в скрипт, код сжат terser.

Шрифт окон: Roboto Condensed (600, 700), файлы в assets/fonts, лицензия SIL Open Font License 1.1 (assets/fonts/OFL-Roboto-Condensed.txt). Шрифт регистрируется только для панели и на шрифты страницы не влияет.
