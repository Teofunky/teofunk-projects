=== Kozlov Import ===
Версия 1.1.0. Перенос контента старого kozlovclub.ru (дамп от 22.10.2026) в Kozlov Core.

Требует активный Kozlov Core. Запуск: Инструменты → Импорт Kozlov, шаги сверху вниз.
В пакете: 17 пользователей, 40 страниц, меню main-menu, 4090 концертов с 1 января 2025 (из них 194 будущих), ссылки на фото.
Шаг «Фото» качает файлы со старого сайта (если он доступен) или из Wayback Machine, сначала для ближайших концертов.
Каждый шаг можно запускать повторно: записи обновляются по старому ID, дублей не будет.
Плагин можно удалить после импорта: данные остаются.
