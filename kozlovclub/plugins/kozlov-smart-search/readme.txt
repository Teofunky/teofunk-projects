=== Kozlov Smart Search ===
Requires at least: 5.3
Tested up to: 6.7
Requires PHP: 7.2
Stable tag: 1.0.4
License: GPLv2 or later

Мгновенный поиск по будущим концертам и страницам сайта kozlovclub.ru.

== Что делает ==

* Ищет по названию, дате, дню недели, сцене, жанру, цене и по тексту анонса.
* Понимает опечатки, неверную раскладку клавиатуры, латиницу и кириллицу.
* Показывает результаты под строкой поиска темы, пока посетитель печатает.

== Чего не делает ==

* Не меняет файлы темы.
* Не пишет в события, страницы и таблицы календаря: только читает.
* Не делает запросов к базе на нажатие клавиши: поиск идёт в браузере по готовому индексу.
* Не добавляет на страницы стилей и глобальных переменных, не использует jQuery.

Собственные данные плагина: одна запись настроек (kss_settings), временный кэш индекса и пустой файл блокировки во временной папке сервера.
При удалении плагина они стираются.

== Установка ==

1. Плагины → Добавить новый → Загрузить плагин → выбрать kozlov-smart-search.zip → Установить → Активировать.
   После активации на сайте ничего не меняется: режим по умолчанию «Выключен».
2. Настройки → Kozlov Smart Search. Нажмите «Сверить с афишей»: должно быть «Совпало: N из N».
3. Режим «Проверка» → Сохранить. Поиск виден только администраторам и по секретной ссылке со страницы настроек.
4. Режим «Включён для всех» → Сохранить → сбросить кэш страниц (Performance → Purge All Caches).

== Обновление ==

1. Настройки → Kozlov Smart Search → режим «Проверка» → Сохранить. Новая версия сохранит этот режим: гости её не увидят, пока вы проверяете.
2. Плагины → Добавить новый → Загрузить плагин → выбрать zip → «Заменить установленный».
   Не удаляйте плагин перед установкой: при удалении стираются его настройки.
3. Проверьте поиск как администратор и по секретной ссылке, нажмите «Сверить с афишей».
4. Режим «Включён для всех» → Сохранить → сбросить кэш страниц.
Откат: загрузить zip прежней версии тем же способом, с заменой.

== Как выключить ==

* Настройки → Kozlov Smart Search → «Выключен» → Сохранить. Действует сразу.
* Без входа в админку: строка define( 'KSS_DISABLE', true ); в wp-config.php
  или удаление папки wp-content/plugins/kozlov-smart-search.

== Что изменилось в 1.0.4 ==

* Сбой базы данных при пересборке больше не заменяет рабочий индекс пустым. Ошибка запроса (в том числе когда WordPress возвращает пустой список вместе с ошибкой) считается неудачной сборкой: посетители получают прежнюю копию, новая попытка через 30 секунд. Законно пустая афиша по-прежнему принимается. Ошибка была и в 1.0.2.
* Выключение поиска доходит до уже открытых вкладок: открытая страница сверяется с сайтом раз в 5 минут и при возвращении на вкладку. Ответ 403 (поиск выключен), 404 или 410 (плагин выключен или удалён) убирает наш интерфейс, остаётся штатный поиск темы. Временные сбои (500, нет сети) не выключают поиск: он работает на прежних данных.
* Концерт или слово с названием вроде «constructor» больше не ломают поиск: словари внутри движка созданы без прототипа.
* Выдача поиска не изменилась: 405 сочетаний запросов и фильтров на снимке афиши дают те же результаты, что в 1.0.3.

== Что изменилось в 1.0.3 ==

* В индекс добавлена длительность концерта по времени окончания из календаря (новое 13-е поле записи, в минутах; 0, если окончание не указано). Нужна панели фильтров афиши для «идёт сейчас» и «сегодня».
* Окончание читается, только если в таблице дат календаря есть колонка end; иначе индекс строится как в 1.0.2.
* Прежние поля записи не изменились, поиск работает как раньше.
* В настройках: строка «С временем окончания» и время «начало–конец» в таблице ближайших концертов.
* После обновления индекс пересобирается сам.

== Что изменилось в 1.0.2 ==

* Исправлено время концертов: в 1.0.1 поиск показывал его на 3 часа позже афиши (23:00 вместо 20:00), а у концертов с 21:00 и позже сдвигалась и дата. Теперь дата и время берутся тем же способом, каким их печатает афиша.
* Концерт пропадает из поиска в ту же минуту, когда он пропадает с афиши.
* После обновления индекс пересобирается сам.
* На странице настроек появилась кнопка «Сверить с афишей»: она сравнивает день и время каждого концерта в поиске с карточками на главной странице.

== Что изменилось в 1.0.1 ==

* Индекс всегда собирает только один запрос (файловая блокировка flock). Остальные получают прежнюю копию, при пустом кэше ждут готовую.
* Между пересборками проходит не меньше 20 секунд, после неудачной сборки пауза 30 секунд.
* Концерты, закрытые паролем, в индекс и в тексты анонсов не попадают.
* «Купить билет»: проверяется, что на экране появился виджет именно этого концерта; скрытые остатки прежнего виджета не учитываются. Пока скрипт Ticketscloud не готов, кнопка работает как ссылка на страницу концерта.
* Если тема выведет несколько строк поиска, плагин работает с той, что раскрыта.

== Адреса ==

GET /wp-json/kozlov-search/v1/index   концерты и страницы
GET /wp-json/kozlov-search/v1/texts   словарь текстов анонсов

== Исходный код ==

Читаемые исходники скрипта лежат в папке src. На сайт подключаются сжатые файлы из папки assets.
