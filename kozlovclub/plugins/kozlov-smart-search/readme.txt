=== Kozlov Smart Search ===
Requires at least: 5.3
Tested up to: 6.7
Requires PHP: 7.2
Stable tag: 1.0.1
License: GPLv2 or later

Мгновенный поиск по будущим концертам и страницам сайта kozlovclub.ru.

== Что делает ==

* Ищет по названию, дате, дню недели, сцене, жанру, цене и по тексту анонса.
* Понимает опечатки, неверную раскладку клавиатуры, латиницу и кириллицу.
* Показывает результаты под строкой поиска темы, пока посетитель печатает.

== Чего не делает ==

* Не меняет файлы темы.
* Не пишет в события, страницы и таблицы календаря: только читает.
* Не делает запросов к базе на нажатие клавиши: поиск идёт в браузере по готовому индексу.
* Не добавляет на страницы стилей и глобальных переменных, не использует jQuery.

Собственные данные плагина: одна запись настроек (kss_settings), временный кэш индекса и пустой файл блокировки во временной папке сервера.
При удалении плагина они стираются.

== Установка ==

1. Плагины → Добавить новый → Загрузить плагин → выбрать kozlov-smart-search.zip → Установить → Активировать.
   После активации на сайте ничего не меняется: режим по умолчанию «Выключен».
2. Настройки → Kozlov Smart Search. Сверьте таблицу «Ближайшие концерты в индексе» с афишей.
3. Режим «Проверка» → Сохранить. Поиск виден только администраторам и по секретной ссылке со страницы настроек.
4. Режим «Включён для всех» → Сохранить → сбросить кэш страниц (Performance → Purge All Caches).

== Как выключить ==

* Настройки → Kozlov Smart Search → «Выключен» → Сохранить. Действует сразу.
* Без входа в админку: строка define( 'KSS_DISABLE', true ); в wp-config.php
  или удаление папки wp-content/plugins/kozlov-smart-search.

== Что изменилось в 1.0.1 ==

* Индекс всегда собирает только один запрос (файловая блокировка flock). Остальные получают прежнюю копию, при пустом кэше ждут готовую.
* Между пересборками проходит не меньше 20 секунд, после неудачной сборки пауза 30 секунд.
* Концерты, закрытые паролем, в индекс и в тексты анонсов не попадают.
* «Купить билет»: проверяется, что на экране появился виджет именно этого концерта; скрытые остатки прежнего виджета не учитываются. Пока скрипт Ticketscloud не готов, кнопка работает как ссылка на страницу концерта.
* Если тема выведет несколько строк поиска, плагин работает с той, что раскрыта.

== Адреса ==

GET /wp-json/kozlov-search/v1/index   концерты и страницы
GET /wp-json/kozlov-search/v1/texts   словарь текстов анонсов

== Исходный код ==

Читаемые исходники скрипта лежат в папке src. На сайт подключаются сжатые файлы из папки assets.
