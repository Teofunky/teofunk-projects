=== Kozlov Living Facade (Живой фасад) ===
Version: 1.0.0
Requires PHP: 7.4

Анимированный фасад клуба с карточками вместо слайдера на главной kozlovclub.ru.
Только телефоны (до 767 px). Компьютерная версия не меняется.

Установка
1. Плагины → Добавить новый → Загрузить плагин → kozlov-facade.zip → Активировать.
2. В меню появится «Живой фасад». Сразу после установки режим «Только редакторы и администраторы»,
   в списке три карточки: два концерта из текущего слайдера и свежая Джазета.
3. Откройте главную на телефоне под своим логином редактора или администратора.
   Посетители в это время видят обычный слайдер.
4. Когда всё проверено: «Живой фасад» → «Все посетители с телефонов» → Сохранить → сбросить кэш страниц.

Безопасность
- Тема, её файлы, таблицы и данные не меняются. Своих таблиц нет: две настройки в wp_options.
- Обычный слайдер прячется только после того, как блок успешно встал. Если рисунок не загрузился
  или случилась ошибка, на странице остаётся обычный слайдер.
- ?kzf=off в адресе главной выключает блок для этого просмотра.
- Режим «Выключено» возвращает всё как было. Удаление плагина стирает его настройки.

Карточки
- Мероприятие: вставьте ссылку на страницу концерта. Название, фото, дата, сцена, цена
  и Ticketscloud ID подтягиваются сами, любое поле можно переписать вручную.
  Кнопка «Купить билет» открывает Ticketscloud, без ID ведёт на страницу концерта.
  После начала концерта карточка скрывается сама.
- Картинка со ссылкой: всё остальное (фестиваль, мастер-класс, новость, спецпроект).
- Джазета: номер, дата и главный заголовок берутся со страницы /gazeta/ (обновление раз в 30 минут).
