Шорткод [kozlov_afisha] для посадочных страниц афиши: по жанру, сцене, «сегодня», «на выходных», «бесплатно».

== Что делает ==

* Выводит карточки ближайших концертов в той же разметке, что на главной (стили темы).
* Читает таблицу All-in-One Event Calendar и поля анонсов. Анонсы, тему и главную не меняет.
* Пишет только временный кэш готового списка (5 минут).
* Страницы с шорткодом не попадают в кэш W3 Total Cache целиком, чтобы «сегодня» всегда было сегодня.
* При любой ошибке вместо списка выводится ссылка на главную, страница работает.
* Справка с примерами и списком жанров: «Настройки → Страницы афиши».

== Отключение ==

Деактивация: на страницах вместо афиши будет виден текст шорткода. Удаление: стирается только кэш списков.
