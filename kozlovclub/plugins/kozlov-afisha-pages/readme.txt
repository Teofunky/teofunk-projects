Шорткод [kozlov_afisha] для посадочных страниц афиши: по жанру, сцене, «сегодня», «на выходных», «бесплатно».

== Что делает ==

* Выводит карточки ближайших концертов в той же разметке, что на главной (стили темы).
* Читает концерты Kozlov Core (поля kc_*, сцены kc_stage, жанры kc_genre). Анонсы, тему и главную не меняет.
* Пишет только временный кэш готового списка (до 5 минут, сбрасывается при сохранении анонса).
* Просит W3 Total Cache не кэшировать страницы с шорткодом целиком. Другой серверный кэш (если есть у хостинга) этот флаг может не учитывать.
* Ошибки PHP внутри шорткода перехватываются: вместо списка ссылка на главную. Ошибки чтения календаря и параметров видны вошедшим редакторам.
* Если виджет Ticketscloud не загрузился, «купить билет» ведёт на страницу концерта.
* Справка с примерами и списком жанров: «Настройки → Страницы афиши».

== Отключение ==

Перед деактивацией переведите страницы с афишей в черновики: без плагина на них будет виден текст шорткода. Удаление: стирается только кэш списков и счётчик версии кэша.

== Changelog ==

= 1.0.1 =
* «Вход свободный»: только если в стоимости нет цены и депозита.
* Длинные названия не обрезаются.
* Запасная ссылка «купить билет» на страницу концерта.
* Сброс кэша при сохранении анонса.
* Подсказки редактору: неизвестная сцена или жанр, ошибка чтения календаря. Опечатка в сцене больше не выводит все сцены.
* В справке: проверка данных (повторяющиеся события, нечитаемые даты).

= 1.0.0 =
* Первая версия.

= 1.1.0 =
* Перенос на новый сайт: концерты из Kozlov Core вместо All-in-One Event Calendar. Ключи сцен в шорткоде прежние (main_scene, mansarda, the_beat, myasnitskaya), жанры по названию или ярлыку. «Купить билет» только при открытой продаже.
