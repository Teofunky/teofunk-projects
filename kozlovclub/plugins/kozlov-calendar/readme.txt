Kozlov Calendar 1.0.0

Установка (одинаково на обоих сайтах):
1. Плагины → Добавить новый → Загрузить плагин → kozlov-calendar-1.0.0.zip → Активировать.
2. Настройки → Kozlov Calendar. По умолчанию календарь виден только редакторам и администраторам.
3. Проверьте: кнопка «Календарь» в шапке, выбор дня и периода, адрес страницы после «Показать».
4. Если всё верно, переключите «Кому показывать» на «Всем посетителям».

Как работает:
- Перехватывает нажатие на кнопки темы (.calendar-toggler) и открывает новый календарь вместо старого.
- «Показать» ведёт на главную с ?date1=ГГГГ-ММ-ДД (и &date2=ГГГГ-ММ-ДД для периода).
- Число концертов берётся из Kozlov Core (новый сайт) или из All-in-One Event Calendar (старый сайт).
  Концерты до 07:00 считаются концертами предыдущего дня. Кеш 10 минут, сбрасывается при сохранении концерта.
- Дни без концертов и прошедшие дни неактивны. «Сегодня» берётся по часам сайта, не по часам телефона.
- Стили изолированы (Shadow DOM), тему и другие плагины не трогает. Выключение: режим «Выключен» или деактивация плагина.

Если старая тема не понимает date2 (период показывает только первый день), снимите галочку «Разрешить выбор периода».
