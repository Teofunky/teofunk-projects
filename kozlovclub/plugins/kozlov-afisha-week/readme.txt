=== Kozlov Afisha Week (афиша по неделям) ===
Version: 1.0.1
Requires PHP: 7.2

Афиша главной kozlovclub.ru по неделям. Сразу видны ближайшие 7 дней, под ними кнопка
«Показать концерты 12–18 ноября» и строка «Ещё 256 концертов до 31 декабря», ниже ссылка на календарь.
Каждое нажатие открывает следующие 7 дней.

Зачем: на главной около 300 карточек (два месяца). На телефоне это 7 000 элементов страницы
и 50 000 px высоты; браузер раскладывает их все при загрузке. С плагином видимых карточек около 40,
основная работа телефона при загрузке главной меньше примерно в 3 раза (замер в эмуляции телефона).

Как устроено
- Карточки дальше 7 дней не удаляются: они лежат на странице в <template>. Браузер их не раскладывает
  и не грузит их картинки, пока их не раскроют.
- Фильтры и поиск над афишей (Kozlov Afisha Filters 1.0.8+) перед поиском раскрывают все карточки
  и ищут по всей афише; жанры, сцены и календарь фильтров с первой загрузки считаются по всем концертам.
- «Назад» со страницы концерта возвращает на главную с тем же числом открытых недель.
- Если страница пришла из кэша, сохранённого вчера, наступившие дни раскрываются сами.
- Кнопка «Купить билет» в раскрытой карточке работает как обычно: виджет Ticketscloud ловит клики
  на всём документе, переподключать его не нужно.
- Без JavaScript (или если скрипт плагина не загрузился) под первой неделей обычная ссылка
  «Показать всю афишу» на главную с ?kaw=off, где видны все концерты.
- Работает только на главной без параметров (?date1, ?genre, ?sort, фильтры kaf_*): там афиша и так короткая.
- Тему, базу и события не меняет. Любая ошибка: страница как без плагина.

Установка
1. Сначала Kozlov Afisha Filters 1.0.9 (иначе фильтр на дату дальше недели ничего не найдёт).
2. Плагины → Добавить новый → Загрузить плагин → kozlov-afisha-week.zip → Активировать.
3. После активации режим «Только редакторы»: проверьте главную на телефоне под своим логином.
4. Настройки → Афиша по неделям → «Все посетители» → Сохранить. Кэш главной сбрасывается сам.

Отключение
- Настройки → Афиша по неделям → «Выключено».
- На один заход: адрес с ?kaw=off
- Без админки: define( 'KAW_DISABLE', true ); в wp-config.php или удалить папку плагина, затем сбросить кэш.

- Месяцы в карточках читаются без расширения mbstring, понимается и «мая».
- Убран переход на страницу концерта после «Купить билет»: виджет Ticketscloud и так работает

- Выключение плагина сбрасывает кэш главной.
- Нужен Kozlov Afisha Filters 1.0.9.
