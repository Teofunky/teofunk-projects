=== Kozlov Event Page ===
Версия: 1.2.1
Нужно: WordPress 6.0+, PHP 7.2+ с расширениями dom и mbstring (без них плагин не включается и пишет об этом в админке). Для списка «Новые страницы» и блока «Ещё в этот вечер» нужен Kozlov Smart Search (без него всё остальное работает).

== Что делает ==
Новая страница концерта. Включается для анонса, как только у него есть заглавное фото.
Анонс без фото показывается в старой вёрстке. Тема, данные анонсов и афиша не меняются:
плагин берёт готовую страницу темы и перестраивает блок концерта. Посетитель видит старую страницу,
а в админке появляется строка «Последний сбой», если: разметка не распознана; перенесено меньше 90% текста;
потерялась хоть одна картинка или ссылка из анонса; в шапке анонса есть незнакомый блок; в анонсе есть встроенный блок, который не видео
(карта, виджет); потерялась кнопка Ticketscloud.

Кнопка покупки по типу концерта: билет Ticketscloud; депозит и вход свободный: «Забронировать стол» (звонок)
с номером текстом и «Зал в 3D»; цена есть, продажа не открыта: неактивная кнопка и телефон; прошедший:
«Ближайшие концерты». Заглавное фото становится картинкой для соцсетей в Yoast.
Все цитаты анонса показываются по порядку. «Другие даты выступления» стали маленьким календарём «Даты концерта» под кнопкой
покупки: день недели, число, месяц; текущая дата залита тёмным, остальные ведут на свои страницы,
прошедшие не показываются, на телефоне ряд листается вбок. Блок «Об артисте» из Kozlov Artists
(данные берутся из плагина, нужна версия 0.3.1 или новее): один артист
показывается карточкой (фото, имя, 2 строки, ссылка на страницу артиста), несколько артистов списком,
первые три сразу, остальные по кнопке «Ещё N артистов». Жанры ведут на страницу жанра, если она есть на сайте.
Концерт в 23:59 показывается как «00:00, ночь на …», метки: «Сегодня ночью», «Завтра ночью», «Идёт сейчас».

== Текст сверху и «Важно знать» ==
В анонсе под основным редактором блок «Новая страница: текст сверху и «Важно знать»», два поля:
1. «Коротко о концерте»: 1–3 предложения, первый текст на новой странице. Пусто: берётся первый
   абзац «Текстового поля 1». Если этот же текст остался в «Текстовом поле 1», он не повторяется.
2. «Важно знать»: сноски по одной на строку (адрес и вход, депозит, бронь). Показываются в рамке
   под кнопкой покупки.
Сноски, которые уже написаны в тексте анонса («Внимание!…», депозит, бронь, «вход через», «находится
по адресу»), плагин сам переносит в рамку «Важно знать»: первым абзацем они больше не становятся.
Набранные заглавными переводятся в обычный регистр. «Внимание! Коллектив оставляет за собой право…»
и «Фото для анонса: …» идут мелким шрифтом внизу.
Абзац с двоеточием в конце не переносится: он подводит к тому, что идёт следом (сеты, список, состав).
Галочка «Не забирать сноски из текста анонса» под полями оставляет весь текст анонса на своих местах.
Тексты из полей видны и на старой странице, вверху описания, если такого текста там ещё нет.

== «Важно знать» по сцене ==
Мероприятия → Новые страницы → Настройки → «Важно знать» по сцене. Для каждой сцены заголовок и текст.
Они сами встают первыми в «Важно знать» у всех будущих концертов этой сцены, в том числе уже набранных:
заголовок жирным, текст, ссылка «Открыть на карте». В базу ничего не пишется: текст подставляется
при показе страницы, поэтому смена адреса правится в одном месте. Сразу после установки заполнено
для Мясницкой: «Концерт не на Маросейке» и «Сцена «Unplugged» находится по адресу ул. Мясницкая, 15
(вход через Lions Head Pub)».
Сноска из текста анонса или поля «Важно знать» убирается, только если в ней нет ничего сверх текста сцены
(допускается одно новое слово: «паб» в «вход через паб Lions Head»). Сноска с дополнительной инструкцией
(«вход со двора через арку», «гардероба нет») остаётся, даже если в ней та же улица.
Так же сравниваются сноски из анонса с полем «Важно знать»: сноска из анонса убирается, только если всё
из неё уже есть в поле.
Старая страница: текст встаёт вверху описания, если улицы сцены в описании ещё нет.
Прошедшие концерты текст сцены не получают. В режиме «Выключено» текст сцены не добавляется нигде.
Карта: своя ссылка в настройках («Карта: Маросейка», «Карта: Мясницкая») или поиск адреса в Яндекс Картах.
Она же у кнопки «Маршрут» и у названия сцены в карточке.

== Программа на карточках афиши ==
Если у концерта заполнено «Название программы», оно видно и в афише (главная, страницы жанров, поиск):
в сетке строкой под названием, в слайдере подзаголовком в стиле темы. Если программа уже написана
в названии концерта («Котов: Песни странников») или у слайда уже есть подзаголовок, она не повторяется.
Кому видно, решает тот же режим: «Только редакторы», «Для всех», «Выключено».
После изменения программы кэш главной в W3 Total Cache сбрасывается сам.
Карточки, которые рисует фильтр Kozlov Smart Search, пока без программы.

== Установка ==
1. Плагины → Добавить новый → Загрузить плагин → kozlov-event-page.zip → Установить → Активировать.
2. Режим после установки и повторной активации: «Только редакторы». После обновления плагина
   «Для всех» тоже переключается на «Только редакторы», «Выключено» остаётся как было.
   Гости видят старые страницы, вы и редакторы видите новые. Страницы, которые видят вошедшие,
   плагин помечает «не кэшировать» (DONOTCACHEPAGE и заголовки), чтобы они не попали к гостям.
3. После обновления вверху админки уведомление. Если до обновления был режим «Для всех»,
   в уведомлении кнопка «Вернуть „Для всех“». Сначала проверьте пару концертов, потом нажмите.

== Редакторам ==
1. Мероприятия → Новые страницы: список ближайших концертов без заглавного фото, ближайшие сверху.
2. «Загрузить фото» открывает анонс. Справа блок «Новая страница концерта».
3. Фото: горизонтальное 16:10, от 1600×1000 px (лучше 2400×1500). Рамка показывает, что увидит посетитель.
   Под рамкой проверка: подходит, маловато или пропорции не те.
4. Название программы: по желанию. Если в названии концерта есть «…» после двоеточия, есть кнопка «Подставить».
5. Всё в блоке сохраняется сразу, нажимать «Обновить» не обязательно.

== Включить для всех ==
1. Мероприятия → Новые страницы → «Что видит гость» → «Проверить» в режиме «Только редакторы».
   Должно быть: «Всё правильно: гости видят старую страницу». Если красное сообщение, кэш отдаёт гостям
   версию для редакторов: сбросьте кэш и включите в W3 Total Cache «Не кэшировать страницы для вошедших».
2. Настройки → «Для всех» → Сохранить. Кэш W3 Total Cache сбрасывается сам.
3. Ещё раз «Проверить». Должно быть: «Всё правильно: гости видят новую страницу».
Если хостинг не пустит проверку (защита от ботов), откройте концерт в окне инкогнито.

== Сравнить старую и новую ==
Вошедшим в админку: пункт в верхней чёрной панели на странице концерта,
или добавить к адресу ?kep=old (старая) или ?kep=new (новая, даже без фото). Гостям эти ссылки ничего не меняют.

== Откат ==
Режим «Выключено» или деактивация плагина. Данные анонсов не трогаются. При смене режима и при
деактивации кэш W3 Total Cache сбрасывается сам; другой кэш (хостинга, CDN) сбросьте вручную.
В режиме «Выключено» на старых страницах остаются только тексты из полей «Коротко о концерте» и
«Важно знать» (иначе перенесённая в поле сноска пропала бы). После деактивации их не видно.
Заглавные фото и названия программ лежат в полях _kep_hero_id и _kep_program и остаются на месте.

== Проверить после установки на сайте ==
1. «Купить билет» на новой странице открывает виджет Ticketscloud (и в нижней панели на телефоне).
2. «Что видит гость» → «Проверить», и для надёжности открыть концерт в окне инкогнито:
   в режиме «Только редакторы» должна быть старая страница.
3. Поделиться ссылкой на концерт с фото в Telegram или VK: в превью новое заглавное фото (в режиме «Для всех»).
4. Цена «от» (1.0.15): открыть концерт, где дешёвые места раскуплены; через секунду после загрузки
   в карточке и нижней панели цена самого дешёвого свободного билета. Ответ сайта виден по адресу
   /wp-json/kozlov-event-page/v1/price/<ID записи>: {"min":число}. {"min":null} сразу после установки
   нормален, пока не открыта хоть одна новая страница концерта (сайт запоминает ключ виджета).

== Изменения ==
1.2.1: карточки афиши ставят метку data-kep-prog, если программа концерта уже написана в названии (нужно плагину афиши).
1.2.0: новая страница открывается у всех концертов. Если заглавного фото нет, в шапке берётся обложка концерта или заглушка; старая страница остаётся только когда картинки нет совсем.
1.1.0: перенос на новый сайт (тема kozlov-2026, Kozlov Core). Тип записи concert; заглавное фото и программа читаются из полей
Kozlov Core (kc_hero, kc_program), «Коротко о концерте» и «Важно знать» из kep_lead и kep_notes (их переносит Kozlov Import).
Список «Новые страницы» и «Ещё в этот вечер» берут концерты из Kozlov Smart Search 1.1.0. Кавычки внутри программы
становятся внутренними („“). Разбор страницы и вёрстка без изменений.
1.0.15: цена «от» по свободным билетам Ticketscloud. Страница для гостей лежит в кэше W3 Total Cache
до 12 часов, поэтому цену после загрузки спрашивает kep.js: /wp-json/kozlov-event-page/v1/price/<ID записи>.
Сайт берёт цены у Ticketscloud открытым ключом виджета из шапки темы (запоминается при показе новой
страницы), хранит ответ от 5 минут до часа: чем меньше мест по самой низкой цене, тем чаще. Число меняется, только если самый дешёвый свободный билет дороже цены
анонса (дешёвые места раскуплены); при любом сбое остаётся цена анонса. Выключить без правки плагина:
фильтр kep_live_price. Клик мышью или тачпадом по «Купить билет» на устройствах с сенсорным экраном
открывает окно покупки: виджет Ticketscloud там слушал только касание. Цена берётся по номиналу
билета, без сервисного сбора. Кнопка «Вернуть режим» после обновления теперь сбрасывает кэш W3 Total Cache.

(длинное «Важно знать», раскрытые даты, невысокое окно), снова едет со страницей, а цену и кнопку
