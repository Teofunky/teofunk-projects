=== Kozlov Core ===
Версия 1.0.0. Модель данных сайта Клуба Алексея Козлова.

Что даёт:
- Тип записи «Концерт» (адреса /event/slug/, как раньше), сцены (/stage/...), жанры (/genre/...), теги.
- Поля: дата и время по Москве, тип цены, цена, текст цены, код Ticketscloud, название программы, бронь, «билетов нет», «отменён», большое фото, слайдер, видео, артисты, текстовые блоки, партнёры.
- Старые адреса /ru/event/..., ?genre=jazz и ?sort=main_scene перенаправляются на новые.
- REST: /wp-json/kozlov/v1/concerts, /concerts/{id}, /dictionary.
- Функции для темы и плагинов: kozlov_concert($post), kozlov_concerts($args), kc_price_text($id), kc_stage($id).
- Настройки → Kozlov Core: токен Ticketscloud, телефон, адрес, тексты про депозит.

При удалении плагина концерты не удаляются.
