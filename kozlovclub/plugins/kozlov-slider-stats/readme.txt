=== Kozlov Slider Stats (Слайдер в Метрике) ===
Version: 1.0.0
Requires at least: 5.6
Requires PHP: 7.4

Показывает в Яндекс Метрике, как работает слайдер на главной kozlovclub.ru: показы, листания,
клики по каждому слайду и кнопки покупки, отдельно для десктопа, планшета и телефона.
На телефоне отдельно: «Живой фасад», «Театр теней» и обычный слайдер (если фасад выключен).

Плагин ничего не меняет на странице: не трогает тему, слайдер, фасад, афишу и виджет Ticketscloud.
Скрипт только слушает клики и касания и вызывает ym() того же счётчика 44419291.

Установка
1. В Метрике создать 5 целей типа «JavaScript-событие» (условие «совпадает»):
     Слайдер: показ                          kzsl_view
     Слайдер: листание                       kzsl_swipe
     Слайдер: клик                           kzsl_click
     Слайдер: кнопка покупки                 kzsl_buy
     Слайдер: покупка на следующей странице  kzsl_buy_next
   Цель считает события только с момента создания.
2. Плагины → Добавить новый → Загрузить плагин → kozlov-slider-stats.zip → Активировать.
   Сразу после активации плагин работает для всех посетителей, кэш страниц W3 Total Cache сбрасывается сам.
3. Проверка без отправки в Метрику: открыть https://kozlovclub.ru/?kzsl=debug на телефоне и на компьютере.
   Внизу экрана появится тёмная панель с событиями: показ, показ слайда, листание, клик.
4. Настройки → «Слайдер в Метрике»: общий выключатель, номер счётчика, «не учитывать редакторов»,
   «покупка на следующей странице». Там же таблица целей и подсказки по отчётам.

Что уходит в Метрику
- Цели (см. выше). Каждая цель несёт параметры визита в ветке «Слайдер на главной»:
    вариант (Десктоп, Планшет, Телефон · фасад, Телефон · театр теней, Телефон · обычный слайдер)
      → «Показ слайдера» / «Листание» (стрелки, вкладки, точки, свайп, перетаскивание)
      → «Показ слайда» → «НАНИ ЕВА · 31 дек» → «позиция 2»
      → «Клик» → «НАНИ ЕВА · 31 дек» → «Купить билет» / «Картинка» / «Название» / «Бронь стола» / «Кнопка «…»»
      → «Кнопка покупки» → слайд → тип кнопки
      → «Покупка после клика» → слайд → «этот же концерт» / «другой концерт»
- «Показ» = слайдер хотя бы наполовину на экране не меньше 1 секунды. «Показ слайда» = слайд был
  текущим 1 секунду, пока слайдер на экране (на десктопе слайды листаются сами, поэтому там показов слайдов больше).
- «Покупка на следующей странице»: клик по слайдеру запоминается во вкладке на 2 часа (sessionStorage),
  кнопка покупки на любой другой странице в эти 2 часа даёт цель kzsl_buy_next.

Как читать
1. Отчёты → Технологии → Устройства, цели «Слайдер: показ» и «Слайдер: клик»: CTR = визиты с кликом / визиты с показом.
2. Отчёты → Содержание → Параметры визитов → «Слайдер на главной»: какой слайд и какой вариант работает.
3. Оплаты: в отчёте «+» рядом с «Люди» → Поведение → Параметры визита → «Слайдер на главной» → вариант → «Клик»,
   затем цели «Получение оплаты» (order.paid_online) и «Ecommerce: покупка». Сравнить с тем же сегментом по «Показ слайдера».

Известные ограничения
- Оплата идёт внутри виджета Ticketscloud, и Метрика часто записывает её отдельным визитом, который начинается
  на ticketscloud.com: с 27.10 по 26.11.2026 так было у 854 из 1 543 визитов с целью «Получение оплаты».
  Поэтому «клик по слайдеру → оплата» надо смотреть по людям, а не по визитам. Ticketscloud передаёт в виджет
  идентификатор посетителя Метрики (параметр ym-uid в коде tcwidget.js), поэтому оплата должна привязываться
  к тому же человеку. Это вывод из кода виджета, его надо проверить на данных через неделю.
- Метрика отправляет цель обычным запросом. Если клик ведёт на другую страницу, запрос может оборваться
  переходом; Метрика хранит неотправленные запросы (_ym_retryReqs) и досылает их на следующей странице сайта.
  Если посетитель сразу ушёл с сайта, такой клик может потеряться.
- Названия слайдов на десктопе берутся из заголовка слайдера темы, на телефоне из карточки фасада. Для одного
  концерта они могут отличаться. Дата приводится к одному виду («31 дек»).
- Посетители с блокировщиком рекламы, который режет Метрику, не считаются (как и во всей Метрике).
- Отчёт «Параметры визитов» считает визиты, а не клики: два клика по одному слайду в одном визите дают один визит.
