## Сайт: стек и проверенные факты
- **Стек:** WordPress 6.7.2, PHP 7.4, тема KozlovCLub.
  - Тема написана на коротких тегах `<?` и работает только при `short_open_tag=On`.
- **Плагины:**
  - All-in-One Event Calendar: локально изучена версия 2.3.4. Плагин закрыт в каталоге WordPress 21.08.2025, обновлений не будет.
  - Magic Fields 2.3.3.2, Yoast 21.0, W3 Total Cache.
  - WPGlobus: английская версия выключена.
  - На хостинге Beget стоит антибот-заглушка: запросы через fetch с параметрами получают JS-страницу.
- **Время событий:**
  - В базе хранится как «UTC = московское время на часах». Тема выводит время через `date()` по UTC.
  - Поэтому пояс события должен быть UTC. В списке это пустой пункт под заголовком UTC: значение UTC, просто с пустой подписью.
  - Поясом по умолчанию календарь берёт пояс из `wp_usermeta.ai1ec_timezone` пользователя, затем пояс сайта, затем `gmt_offset`.
- **Жанры:**
  - Хранятся в поле Magic Fields `genre_categories` вариантами «Рус|eng». Фильтр главной `?genre=eng` сравнивает английскую часть.
  - У 7 из 13 пунктов меню «Жанры» нет своих страниц, только фильтр, а он закрыт в robots.txt.
  - «Вход свободный» тоже записан как жанр, по нему плагин страниц афиши определяет бесплатные концерты.
- **Ticketscloud:**
  - Кнопка «Купить» выводится, только если заполнены оба поля: `ticketscloud_link` (код события) и `ticketcloudid`.
  - `ticketcloudid` всегда одна и та же строка, это заголовок JWT `{"alg":"HS256","iss":"ticketscloud.ru","typ":"JWT"}`.
  - Если оба поля пусты, выводится блок депозита и бронирования (single.php, около строки 388).
- **Смена slug:** если поменять адрес (slug) опубликованного концерта, старый адрес отдаёт 404 без переадресации. Пример: Шилклопер, 10.10.

3. **Часовой пояс по умолчанию UTC.** Без кода, в phpMyAdmin, для каждого редактора. Сначала проверка:
   ```sql
   SELECT user_id, meta_value FROM wp_usermeta WHERE meta_key = 'ai1ec_timezone';
   ```
   Если строки для редактора нет:
   ```sql
   INSERT INTO wp_usermeta (user_id, meta_key, meta_value) VALUES (ID, 'ai1ec_timezone', 'UTC');
   ```
   Если есть:
   ```sql
   UPDATE wp_usermeta SET meta_value = 'UTC' WHERE user_id = ID AND meta_key = 'ai1ec_timezone';
   ```
   Начать с одного редактора. Не сделано.
4. **Ticketscloud ID.** Цель: тема перестаёт требовать ID, и поле становится ненужным.
   - Сначала запрос только на чтение: будущие концерты, где заполнено одно поле из двух.
     ```sql
     SELECT p.ID, p.post_title,
       MAX(IF(m.meta_key = 'ticketscloud_link', m.meta_value, NULL)) AS tc_link,
       MAX(IF(m.meta_key = 'ticketcloudid', m.meta_value, NULL)) AS tc_id
     FROM wp_posts p
     JOIN wp_ai1ec_events e ON e.post_id = p.ID
     LEFT JOIN wp_postmeta m ON m.post_id = p.ID AND m.meta_key IN ('ticketscloud_link', 'ticketcloudid')
     WHERE p.post_type = 'ai1ec_event' AND p.post_status = 'publish' AND e.start > UNIX_TIMESTAMP()
     GROUP BY p.ID, p.post_title
     HAVING (COALESCE(tc_link, '') <> '') XOR (COALESCE(tc_id, '') <> '');
     ```
