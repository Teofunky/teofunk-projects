# Жалобы редакторов kozlovclub.ru: разбор

Дата: 13.10.2026. Источники: тема KozlovCLub (single.php, index.php через редактор тем, только чтение), Magic Fields 2.3.3.2 (multiline_field.php), исходники All-in-One Event Calendar 2.3.4 (локальная копия).

1. Черновик показывает пустую страницу и дату «01 ЯНВ 00:00, четверг».
   - single.php, строки 7-15: события берутся SQL-запросом с WHERE wp.post_status = 'publish'.
   - Строки 42-48: данные страницы ($event, мета-поля) ищутся только в этом списке. У черновика $event пустой, поэтому нет полей, а дата = метка 0 = 01.01.1970 (четверг), 00:00.
   - Решение: в строке 12 добавить OR wp.id = текущий ID (1 строка в теме) или изолированный плагин с фильтром запроса только для предпросмотра.
2. «Add Another» переключает поля в Visual.
   - MF2 рисует свои вкладки HTML/Visual; по умолчанию Visual.
   - В поле есть опция «Hide Visual Editor for this field» (multiline_field.php, стр. 52-57) и общая настройка hide_visual_editor (стр. 91).
3. Часовой пояс.
   - Пустой пункт после «UTC» в списке и есть UTC (у зоны нет региона, поэтому подпись пустая).
   - Пояс по умолчанию берётся по порядку: мета пользователя ai1ec_timezone, затем timezone_string сайта, затем gmt_offset (lib/date/timezone.php, get_default_timezone).
   - Тема выводит время через date() по UTC (single.php 133-135), поэтому любой пояс, кроме UTC, сдвигает время на сайте.
4. Ticketscloud ID.
   - Константа = JWT-заголовок {"alg":"HS256","iss":"ticketscloud.ru","typ":"JWT"}, не секрет.
   - Кнопка выводится, только если заполнены оба поля, ticketscloud_link и ticketcloudid (single.php 214).
   - Если оба пусты, выводится другой блок (стр. 388). Поэтому подставлять ID всегда нельзя: только когда заполнена ссылка.
5. Жанры.
   - Хранятся в поле MF2 genre_categories как варианты «Рус|eng».
   - Фильтр на главной ?genre=eng сравнивает английскую часть (index.php 444-460), так что новый вариант заработает в фильтре сам. Пункт меню добавляется вручную.
   - В меню «Жанры» у 7 из 13 пунктов нет страницы, только ?genre=, а этот адрес закрыт в robots.txt.

Побочные находки в single.php:
- Запрос без LIMIT грузит все экземпляры всех опубликованных событий на каждой странице концерта.
- Ссылки собираются как /{lang}/event/slug: с /ru/ и без слэша, отсюда редиректы.
