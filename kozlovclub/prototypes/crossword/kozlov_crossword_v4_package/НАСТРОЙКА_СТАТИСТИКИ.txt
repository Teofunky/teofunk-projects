ПОДКЛЮЧЕНИЕ СБОРА СТАТИСТИКИ К КРОССВОРДУ

Что уже работает без настройки:
• интерактивный кроссворд
• шкала прогресса
• финальный экран при 100%
• кнопка «Забрать билеты»
• переход в Telegram к @chepmodel
• заранее набранное сообщение «Я разгадал кроссворд»

Почему для общей таблицы нужен отдельный шаг:
Статический HTML в браузере не может сам дописывать общую Excel-таблицу на сервере.
Нужна точка приёма данных. Самый простой вариант — Google Sheets + Apps Script.
Эту таблицу в любой момент можно скачать как .xlsx.

НАСТРОЙКА ЗА 5 МИНУТ

1. Создайте новую Google-таблицу.
2. Откройте: Расширения → Apps Script.
3. Удалите стандартный код и вставьте содержимое файла collector_google_sheets.gs.
4. Нажмите Deploy / Развернуть → New deployment / Новое развертывание.
5. Тип: Web app / Веб-приложение.
6. Execute as / Выполнять от имени: Me / Я.
7. Who has access / Доступ: Anyone / Все.
8. Скопируйте адрес Web app, который заканчивается на /exec.
9. Откройте index.html в текстовом редакторе.
10. Найдите строку:
    const COLLECTOR_URL = "";
11. Вставьте URL между кавычками:
    const COLLECTOR_URL = "https://script.google.com/macros/s/....../exec";
12. Загрузите index.html на сайт.

КАКИЕ ДАННЫЕ СОБИРАЮТСЯ

Каждому браузеру присваивается случайный Session ID. Таблица хранит:
• когда человек начал
• когда был активен последний раз
• процент заполнения
• сколько слов угадано
• завершён ли кроссворд
• время завершения
• нажал ли «Забрать билеты»
• последнее событие
• источник перехода и адрес страницы

Важно: обычная веб-страница не может узнать Telegram-ник пользователя без отдельной авторизации через Telegram.
Поэтому участник в аналитике определяется по анонимному Session ID, а после 100% сам пишет менеджеру в Telegram и присылает скриншот.

Если нужна именно идентификация по имени / Telegram до начала игры, можно добавить одно короткое поле перед стартом.
