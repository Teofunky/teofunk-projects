Kozlov Club — точечные изменения темы (13.10.2026)

СОДЕРЖАНИЕ
  single.php — шаблон мероприятия
  index.php — шаблон главной/афиши

ИЗМЕНЕНИЯ
  single.php
  1. В режиме is_preview() разрешено включать в SQL-запрос только текущую
     неопубликованную запись, которую пользователь вправе редактировать.
  2. Если нет записи в wp_ai1ec_event_instances, редактор увидит сообщение,
     а ложная дата 01.01.1970 больше не появится.
  3. Ссылки на соседние концерты и другие выступления артиста формирует
     get_permalink(), а не CONCAT('/ru/event/', slug).
  4. В навигации проверяется наличие соседних элементов массива.
  index.php
  5. Ссылки на события в слайдере и карточках афиши формирует get_permalink().

НЕ ИЗМЕНЕНО
  AI1EC / Magic Fields / Ticketscloud / время / жанры / БД / другие файлы.

ПЕРЕД ЗАМЕНОЙ
  1. Сохранить оригиналы single.php и index.php вне сервера.
  2. Убедиться, что загруженные файлы — копия именно активной темы.
  3. По возможности испытать изменения на staging; если нет — в окно
     низкой нагрузки с готовым быстрым откатом.
  4. Загружать только в каталог действующей темы, НЕ в корень WordPress.
  5. Проверить опубликованный концерт, черновик, pending/future, доступ
     без авторизации, первый/последний концерт, афишу, слайдер,
     русские и (если используются) английские ссылки.
  6. Если исправление не работает, вернуть оба оригинала; не менять БД.

ВАЖНО
  Предпросмотр нового события зависит от наличия строки в таблице
  wp_ai1ec_event_instances. Несохранённые изменения метаполей не
  обязательно показываются в WordPress preview (проверить отдельно).
  get_permalink() зависит от правил постоянных ссылок и WPGlobus —
  проверить реальный canonical после установки.
  Проверка PHP-синтаксиса выполнена PHP 8.4 CLI с short_open_tag=1;
  исполняемого PHP 7.4 в среде не было. Все новые конструкции совместимы
  с синтаксисом PHP 7.4, но непосредственно на 7.4 тест не выполнялся.
  В исходном коде уже широко используются короткие PHP-теги <?.
  Убедитесь, что short_open_tag=On в рабочем окружении.
