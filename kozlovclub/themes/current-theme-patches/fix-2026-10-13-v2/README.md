# Правки темы KozlovCLub, версия 2 (13.10.2026)

Сводная версия: правки из присланного kozlov_theme_patch.zip плюс две правки из моей первой версии (защита ?view= и implode). Заменяет kozlov-theme-fix-2026-10-13.zip.

## Что изменено
single.php:
1. Предпросмотр черновиков: черновик попадает в выборку только при предпросмотре и только для того, кто может его редактировать.
2. Если у события нет даты в календаре, редактор в предпросмотре видит сообщение вместо ложной даты 01.01.1970. Посетителю ничего не выводится.
3. Ссылки на соседние концерты и другие даты артиста строит WordPress (get_permalink): сразу правильный адрес /event/имя/, без /ru/ и переадресации.
4. Проверка, что соседний концерт существует (первый и последний концерт больше не дают ошибок в журнале).
5. Два вызова implode с аргументами в старом порядке: на PHP 7.4 только предупреждение, на PHP 8 страница концерта обрывается на строке жанров.

index.php:
6. Ссылки на концерты в слайдере и в афише строит get_permalink.
7. Параметр ?view= принимает только line или cell. В оригинале в адрес можно подставить свой HTML/скрипт, и он выводится на главной (XSS).

Построчно: changes.diff (сравнение с присланными оригиналами).

   - single.php (оригинал): c3c2c03849fcb67eeb6c876dbb5040019e2f6bc5c34fd1dc1e6eeb0cedc7e40c

3. Залей в wp-content/themes/KozlovCLub/ через файловый менеджер Beget.
   - single.php (новый): b106fe70cca16d31ab9009c282ec45c8d4ec9cf364528b315015fe09fca31805
   - index.php (новый): 1161eb31d6aa3f66736bae465825fe878f8975a492b395577efefda4865a4d58
4. Performance → Purge All Caches.

## Проверить сразу после
1. Будущий опубликованный концерт: дата, цена, «Купить», ссылки «предыдущий / следующий» ведут на https://kozlovclub.ru/event/имя/.
2. Первый и последний концерт в афише открываются без ошибок.
3. Главная: афиша, слайдер, плитка и список, ссылки на концерты.
4. Предпросмотр черновика (The Creators): фото, тексты, дата.
5. Тот же адрес предпросмотра в окне инкогнито: 404.
6. /?view=test открывает обычную плитку.

## Как проверено
- Синтаксис с short_open_tag=On, PHP 7.4+ (PHPCompatibility): замечаний нет.
- Локальный WordPress 6.7.2, заглушка темы, тестовые события, PHP 8.3. Все три версии (моя первая, присланная, сводная) на одних тестах:
  - предпросмотр черновика с датой: текст и дата есть у сводной и моей первой; у присланной текста нет (обрыв страницы на implode под PHP 8);
  - черновик без даты: сводная и присланная показывают сообщение, моя первая показывала заголовок с неверной датой;
  - черновик без входа: 404 у всех;
  - черновик не попадает в «следующий концерт»: у всех;
  - ?view= со скриптом: скрипт выводится только у присланной.
- Не проверено: PHP 7.4 и настоящий календарь All-in-One Event Calendar.
