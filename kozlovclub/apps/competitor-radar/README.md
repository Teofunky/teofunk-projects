# «Обзор конкурентов» — веб-приложение для Клуба Алексея Козлова

Рабочий MVP собирает афиши и публичные упоминания конкурентов, устраняет дубли и формирует краткую управленческую сводку за неделю или произвольный период.

## Что уже работает

- восемь основных конкурентов: Клуб Игоря Бутмана, Эссе, Louis, Академ Джаз Клуб, Союз Композиторов, Jam Club Music, Rhythm & Blues Cafe, Gamma More;
- официальные сайты клубов;
- агрегаторы: JazzMap; дополнительные адаптеры Яндекс Афиши, Ticketland и MTS Live подготовлены, но по умолчанию выключены из-за возможных антибот-ограничений;
- новостные RSS-поиски по каждой площадке;
- фильтр по датам и площадкам;
- выявление артистов/программ, фестивалей, премьер, зарубежных привозов, трибьютов, джемов, бранчей, ночных форматов, скидок, коллабораций и иных PR-сигналов;
- подсчёт объёма афиши, уникальных программ, цен, повторяющихся форматов и пересечений с афишей Клуба Алексея Козлова;
- экспорт в Markdown и CSV;
- автоматический еженедельный запуск по понедельникам в 09:00 по Москве;
- история запусков и диагностика каждого источника.

## Запуск на Mac

1. Распакуйте папку.
2. Дважды нажмите `start.command`.
3. Разрешите запуск в macOS, если система спросит.
4. Откроется `http://127.0.0.1:8765`.

Нужен Python 3.11 или новее. При первом старте создаётся виртуальное окружение и устанавливаются зависимости.

## Запуск через Terminal

```bash
cd competitor_review_app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

## Запуск через Docker

```bash
docker compose up -d --build
```

После запуска: `http://localhost:8765`.

## Настройка источников

Файл `config/sources.yaml` содержит все площадки, алиасы и URL. Поле `enabled: false` включает источник в конфигурацию, но не запускает его. Для активации замените значение на `true`.

При изменении структуры сайта обычно достаточно заменить URL или добавить более специализированный CSS-селектор в `app/scraper.py`. Сначала парсер ищет Schema.org/JSON-LD Event, затем типовые карточки событий и даты в DOM.

## Расписание

Параметры находятся в `.env`:

```env
TIMEZONE=Europe/Moscow
WEEKLY_DAY=mon
WEEKLY_HOUR=9
WEEKLY_MINUTE=0
```

Еженедельный отчёт сохраняется в `data/reports/` в форматах Markdown и JSON.

## Важные ограничения

- сайты могут менять верстку, robots.txt и антибот-политику; в интерфейсе виден статус каждого источника;
- приложение не обходит авторизацию, CAPTCHA, платный доступ и технические ограничения площадок;
- определение «привоза» и типа PR-активности основано на явных словах в анонсе; сомнительные случаи нужно проверять редактору;
- Google News RSS может давать повторы или нерелевантные совпадения, которые приложение старается дедублицировать;
- для стабильной промышленной эксплуатации желательно раз в месяц проверять источники и сохранять HTML-фикстуры для тестов.

## Проверка тестов

```bash
pytest -q
```

## Структура

- `app/main.py` — API, веб-интерфейс и еженедельное расписание;
- `app/scraper.py` — загрузка и парсинг;
- `app/classification.py` — категории и эвристики;
- `app/analyzer.py` — дедупликация, сравнительная аналитика и экспорт;
- `app/db.py` — SQLite;
- `config/sources.yaml` — площадки и источники;
- `data/reports/` — готовые отчёты.
