# Конкурентный радар Клуба Алексея Козлова — версия 2.0

Отдельное локальное веб-приложение для программного отдела, маркетинга и руководства. Оно собирает афиши и публичные инфоповоды конкурентов, формирует единый реестр артистов и сравнивает каждое выступление с публичной и внутренней афишей Клуба Алексея Козлова.

## Главная логика

Сервис отвечает не только на вопрос «что опубликовано у конкурентов», но и на вопросы:

- какие артисты играют у каждого клуба;
- у кого и в какие даты выступает тот же артист, что и в Клубе Козлова;
- есть ли выступление одного артиста в один день или в пределах 1–14 дней;
- какие даты перегреты похожими жанрами и большим количеством конкурентных концертов;
- кто усиливает афишу, привозит зарубежных артистов, запускает фестивали и новые форматы;
- какие PR-механики, акции, партнёрства и инфоповоды использует рынок;
- какие конкретные действия стоит передать программному отделу и маркетингу.

## Источники

В конфигурацию включены официальные сайты и резервные агрегаторы для:

1. Клуба Игоря Бутмана;
2. «Эссе»;
3. Louis;
4. Академ Джаз Клуба;
5. Союза Композиторов;
6. Jam Club Music;
7. Rhythm & Blues Cafe;
8. Gamma More;
9. Клуба Алексея Козлова — как полноценной сравниваемой площадки.

Также подключены Ticketland, Яндекс Афиша, Афиша.ru, MTS Live, JazzMap, официальные публичные Telegram-страницы и новостные RSS-поиски. Каждый источник имеет отдельный именованный адаптер или специальный API-парсер. Если сайт изменил структуру, раздел «Источники» показывает состояние `empty` или `error`, а не молча выдаёт неполный отчёт.

## Что есть в интерфейсе

### Резюме

- главные изменения периода;
- риски для Клуба Козлова;
- возможности для программирования;
- рекомендуемые действия для команды;
- рейтинг конкурентного давления с раскрываемыми фактическими основаниями.

### Все артисты

Полный список распознанных артистов с колонками:

- даты в Клубе Козлова;
- клубы-конкуренты;
- даты у конкурентов;
- совпадение в один день;
- ближайший временной разрыв.

Есть поиск и фильтр «только общие с Клубом Козлова».

### Пересечения

Для каждого общего артиста показывается пара событий:

- концерт в Клубе Козлова;
- концерт у конкурента;
- площадка, программа и дата;
- разрыв в днях;
- отдельная красная маркировка совпадения день-в-день.

### Календарь рисков

По каждой дате сопоставляются наша афиша и конкуренты. Риск повышается при:

- совпадении артиста;
- совпадении жанра;
- высокой плотности конкурентных событий.

### Вся афиша

Единая таблица всех концертов Клуба Козлова и конкурентов: дата, сцена, артист, программа, цена, категории и ссылки на все источники.

### PR и инфоповоды

Лента публикаций с классификацией: фестиваль, премьера, релиз, юбилей, привоз, коллаборация, партнёрство, скидка, sold out, дополнительный концерт и другие сигналы.

### По клубам

Для каждого конкурента:

- количество событий и артистов;
- изменение к предыдущему сопоставимому периоду;
- общие артисты с Клубом Козлова;
- привозы и специальные форматы;
- минимальная и медианная цена;
- основные жанры и заметные активности;
- индекс конкурентного давления.

### Склейка артистов

Ручной справочник алиасов устраняет различия вроде «Ivan Ivanov Quartet», «Квартет Ивана Иванова» и «Иван Иванов Trio». Каноническое имя используется во всех сравнениях и экспортируется в отчёты.

## Внутренняя афиша Клуба Козлова

Есть два способа добавить ещё не опубликованное расписание.

### CSV

В интерфейсе загрузите файл с колонками:

```text
date,time,title,stage,price,description
```

Пример: `examples/kozlov_schedule_example.csv`.

### Google Calendar через ICS

В `.env` укажите секретные ICS-ссылки четырёх календарей, разделяя их точкой с запятой:

```env
KOZLOV_ICS_URLS=https://...basic.ics;https://...basic.ics
```

Сервис добавит эти события как источник с максимальным приоритетом. Секретные ссылки нельзя публиковать или передавать посторонним.

## Экспорт и доставка

- `Артисты CSV` — реестр артистов и пересечений;
- `Афиша CSV` — полная таблица событий;
- `Резюме MD` — управленческий отчёт;
- `Печать / PDF` — печатная версия первого экрана;
- Telegram и email — доступны после заполнения параметров в `.env`.

## Запуск на Mac

1. Распакуйте архив.
2. Дважды нажмите `start.command`.
3. При первом запуске создастся `.venv` и установятся библиотеки.
4. Браузер откроет `http://127.0.0.1:8765`.

Требуется Python 3.11 или новее.

Запуск из Terminal:

```bash
cd competitor_review_app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

## Docker

```bash
docker compose up -d --build
```

После запуска откройте `http://localhost:8765`.

## Еженедельный запуск

По умолчанию сбор запускается каждый понедельник в 09:00 по Москве. Параметры находятся в `.env`:

```env
TIMEZONE=Europe/Moscow
WEEKLY_DAY=mon
WEEKLY_HOUR=9
WEEKLY_MINUTE=0
```

## Важные ограничения

- Сервис не обходит CAPTCHA, авторизацию, платный доступ, robots.txt и запреты площадок.
- Публичные сайты и агрегаторы могут менять HTML; поэтому состояние каждого источника видно отдельно.
- Определение артиста из сложного рекламного заголовка основано на правилах и справочнике алиасов. Строки «Не распознан» нужно просматривать и при необходимости добавлять алиас.
- Социальные показатели охвата, лайков и рекламного бюджета нельзя достоверно получить из публичного HTML всех площадок. Для этих метрик потребуются официальные API и права доступа.
- Автоматические рекомендации формируются только из сохранённых фактов; при недостатке данных сервис сообщает об этом.

## Архитектура

- `app/parsers.py` — адаптеры официальных сайтов и агрегаторов;
- `app/scraper.py` — загрузка, robots.txt, WordPress API, RSS, Telegram и ICS;
- `app/artists.py` — извлечение и нормализация артистов;
- `app/analyzer.py` — реестр артистов, сравнение с Клубом Козлова, календарь рисков и резюме;
- `app/db.py` — SQLite, история, алиасы и импорт CSV;
- `app/delivery.py` — Telegram/email;
- `config/sources.yaml` — полный список источников;
- `config/artist_aliases.yaml` — стартовый справочник имён.
