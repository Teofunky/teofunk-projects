Музыкальная газета клуба по адресу /gazeta/: редакция, ручное утверждение выпусков владельцем, подшивка.

== Описание ==

Газета — самостоятельная страница сайта: без шапки, меню и подвала темы клуба; на сайт клуба ведёт ссылка «← На сайт Клуба Козлова» вверху (и такая же в выходных данных). Три вида газеты — «Газета», «Современный», «Кратко» — читатель переключает сам; адреса и тексты одни. Читатель видит только утверждённые выпуски. Автоматика (импорт JSON 1.1 через REST) готовит только черновики; публикует и открывает газету читателям только выбранный владелец, вручную.

Данные, адреса, роли, режимы и формат JSON совместимы с 0.3.4, 0.3.5 и 0.4.0: обновление и откат — замена кода, без переноса данных; 0.5.0 добавила таблицу wp_es_meta (обложка и блоки статей), 0.5.1 — указатель поиска wp_es_search, 0.5.5 — столбец topics в нём; старые версии их не трогают.

Порядок установки, обновления и отката: docs/UPGRADE-ROLLBACK.md.
Что проверено и что нет: docs/TEST-REPORT.md.
Неизменяемые договорённости (таблицы, адреса, REST, проверки): docs/CONTRACT.md.
Изменения: docs/CHANGELOG.md.

== Аварийная остановка ==

Пустой файл DISABLE-GAZETA в папке плагина или define('KOZLOV_GAZETA_DISABLED', true) в wp-config.php — модули газеты не загружаются, сайт клуба работает, данные сохраняются. Если не помогло — переименовать только папку kozlov-jazzeta.

== Удаление ==

Удаление плагина ничего не стирает из базы.

== Changelog ==

= 0.5.5 =
«Россия / Мир» работают в виде «Кратко» (правило вида перебивало скрытие). Чипы «В номере» фильтруют номер. Автоматические темы (Релизы, Концерты, Фестивали, Конкурсы и премии, Интервью, Юбилеи, Памяти, Кино и книги): не больше двух на материал, ручная замена в редакции, поиск по теме /gazeta/search/?tema=…. Указатель поиска получает столбец topics и пересобирается при «Завершить обновление».

= 0.5.4 =
Без точки после названия газеты: шапка, выходные данные, карточки для соцсетей, шапка редакции и предпросмотр в «Оформлении». В шапке редакции и на карточке-превью — название из «Оформления», а не «Ежедневный стандарт».

= 0.5.3 =
Кроссворд на телефоне: сетка целиком по ширине экрана, своя клавиатура газеты (ЙЦУКЕН, ⌫, ⇄) с текущим вопросом над ней, компактные кнопки; системная клавиатура — по выбору читателя. Компьютер и планшет без изменений.

= 0.5.2 =
Кроссворд недели: загрузка слов и вопросов (JSON es-crossword-1.0 или строки), сборка сетки, страница с игрой, архив, ответы через неделю.

= 0.5.1 =
Поиск по газете (/gazeta/search/), кадр фото по точке фокуса, фото в «Кратко» на ширину колонки.

= 0.5.0 =
* Три вида газеты — «Газета», «Современный», «Кратко» — на одних адресах; панель «Оформление» у читателя: вид, светлая/тёмная палитра, размер текста 90–140 %, плотность.
* Обложка номера, блоки «Почему это важно / Контекст / Что дальше» и «Что известно» по выбору редактора (новая таблица wp_es_meta).
* Вид по умолчанию и предпросмотр трёх видов в «Оформлении»; сброс кэша только адресов газеты.
* JSON 1.1, адреса, роли и ручная публикация без изменений. Подробно — docs/CHANGELOG.md.
