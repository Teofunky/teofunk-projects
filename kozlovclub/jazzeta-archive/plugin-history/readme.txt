Музыкальная газета клуба по адресу /gazeta/: редакция, ручное утверждение выпусков владельцем, подшивка.

== Описание ==

Газета — самостоятельная страница сайта: без шапки, меню и подвала темы клуба; на сайт клуба ведёт ссылка «← На сайт Клуба Козлова» вверху (и такая же в выходных данных). Три вида газеты — «Газета», «Современный», «Кратко» — читатель переключает сам; адреса и тексты одни. Читатель видит только утверждённые выпуски. Автоматика (импорт JSON 1.1 через REST) готовит только черновики; публикует и открывает газету читателям только выбранный владелец, вручную.

Данные, адреса, роли, режимы и формат JSON совместимы с 0.3.4, 0.3.5 и 0.4.0: обновление и откат — замена кода, без переноса данных; 0.5.0 добавила таблицу wp_es_meta (обложка и блоки статей), 0.5.1 — указатель поиска wp_es_search, 0.5.5 — столбец topics в нём; старые версии их не трогают.

Порядок установки, обновления и отката: docs/UPGRADE-ROLLBACK.md.
Что проверено и что нет: docs/TEST-REPORT.md.
Неизменяемые договорённости (таблицы, адреса, REST, проверки): docs/CONTRACT.md.
Изменения: docs/CHANGELOG.md.

== Аварийная остановка ==

Пустой файл DISABLE-GAZETA в папке плагина или define('KOZLOV_GAZETA_DISABLED', true) в wp-config.php — модули газеты не загружаются, сайт клуба работает, данные сохраняются. Если не помогло — переименовать только папку kozlov-jazzeta.

== Удаление ==

Удаление плагина ничего не стирает из базы.

= 0.5.10 =
Для поисковиков и мессенджеров (по отчёту проверки сайта): адрес без косой черты на конце («/gazeta/2026-10-21») отвечает 301 на адрес с чертой, а не второй копией страницы (строка запроса, например ?q= поиска, сохраняется; ситемапы и адреса ?es_view= не трогаются); description не длиннее 158 знаков и режется по слову, у выпуска — столько заголовков, сколько влезает; title материала и кроссворда не длиннее 65 знаков (полное название газеты, иначе его последнее слово, иначе один заголовок); у подшивки, кроссвордов, выпусков без фото на обложке и материалов без картинки в og:image подставляется картинка сайта по умолчанию из Yoast (иначе логотип газеты). Данные, адреса и база не меняются.

Данные, адреса и база не меняются.
