# Установка, обновление с 0.3.x / 0.4.0 / 0.5.x и откат — 0.5.6

Пакет 0.5.6 собран и проверен вне сайта (см. `TEST-REPORT.md`) и никуда не устанавливался. Он включает 0.5.5, ставить 0.5.5 отдельно не нужно. **На рабочем сайте kozlovclub.ru сейчас 0.5.4** (видно в списке плагинов 23.10.2026, только просмотр); там опубликованы № 001–003.
**Порядок: сначала тестовая копия сайта, потом — только по отдельному решению владельца — рабочий сайт.**

## 0. Что нужно до начала

1. **Резервная копия файлов и всей базы**, восстановление которой проверено на копии. Отдельно сохраните таблицы `wp_es_*` и строки `wp_options` с именами `es_%` — это все данные газеты.
2. Доступ к файловому менеджеру или SFTP без WordPress (чтобы при необходимости переименовать одну папку).
3. ZIP прежней версии (0.3.4 на рабочем сайте; 0.5.2 на тестовой копии) — для отката.
4. Исключения кэша страниц на всех уровнях (W3 Total Cache, Nginx/прокси Beget, CDN), действующие до PHP:
   - `/gazeta` и `/gazeta/*`;
   - `/wp-json/ezhednevny-standard/v1/*` и `?rest_route=/ezhednevny-standard/v1/...`;
   - любые адреса с параметром `es_view`.
   Статику (CSS, JS, шрифт, SVG) кэшировать можно. Плагин сам ставит `DONOTCACHEPAGE` и `Cache-Control: private, no-store` для закрытых страниц, но кэш до WordPress этого не видит.
5. Окно работ, когда никто не правит газету.

Проверка ZIP: `sha256sum kozlov-jazzeta-0.5.6.zip` должен совпасть с файлом `kozlov-jazzeta-0.5.6.zip.sha256`.

**0.5.4 или 0.5.5 → 0.5.6:** шаги и база — как ниже для 0.5.5. В 0.5.6 сверх 0.5.5 меняется только вывод, данных это не касается. После «Завершить обновление» проверить:
- под карточками номера — только «Источник↗ · Тема»;
- в шапке нет «5 материалов · ≈ 4 мин чтения»;
- в материале про Animative подпись к фото без «Кадрирование…», «Wikimedia Commons» и «CC BY 2.0» — ссылки, в «Источниках» две строки, справа нет «Проверки»;
- в редакции у этого материала — блок «Текст и подача».

Откат на 0.5.5 или 0.5.4 — ZIP той версии с заменой и «Завершить обновление».

**0.5.4 → 0.5.5 (рабочий сайт сейчас):**
- **База:** в производную таблицу `wp_es_search` добавляется столбец `topics`. Это делает dbDelta при «Завершить обновление», затем указатель поиска пересобирается. Для № 001–003 это доли секунды. Остальные таблицы не меняются. Новых опций нет, кроме временной `_transient_es_topic_counts`.
- **Шаги:**
  1. Резервная копия хотя бы таблиц `wp_es_*`.
  2. «Плагины» → «Добавить» → «Загрузить» → `kozlov-jazzeta-0.5.5.zip` → «Заменить текущую».
  3. «Редакция газеты» → «Режим» → **«Завершить обновление»**. До этого газета отвечает 503, сайт клуба работает.
- **Проверить:**
  - `/gazeta/`, вид «Кратко»: «Россия» оставляет только российские материалы; «Релизы» — только релизы; «Россия» + «Релизы» → «В этом номере таких материалов нет»;
  - у материалов в строке сведений — тихая ссылка «Релизы» и т. п.;
  - `/gazeta/search/?tema=releases` — список релизов, ряды «Рубрики» и «Темы»;
  - в редакции, в свойствах любого материала, — блок «Темы для поиска».
- **Откат на 0.5.4:** загрузить ZIP 0.5.4 с заменой → «Завершить обновление». Ручные темы останутся в `wp_es_meta` и вернутся вместе с 0.5.5. Столбец `topics` 0.5.4 не мешает.

**0.5.2 или 0.5.3 → 0.5.4 (тестовая копия сейчас).** То же, что ниже для 0.5.3, плюс название в шапке без точки. База не меняется.

**0.5.2 → 0.5.3:**
- Меняются только скрипт, стили и разметка страницы кроссворда, база не меняется.
- Шаги — те же, что в п. 2. Если заменить плагин без деактивации, он попросит «Завершить обновление», потому что сменилась версия. Кроссворд № 002 и прогресс читателей останутся.
- Проверить на телефоне: страница кроссворда номера → касание клетки → клавиатура газеты. Ссылка «Печатать клавиатурой телефона» должна вернуть обычный ввод.

## 1. Снимок данных до обновления (только чтение)

В 0.3.x нет экрана «Проверка данных», поэтому до обновления запишите числа запросами в phpMyAdmin (они ничего не меняют; префикс `wp_` замените на свой):

```sql
SELECT state, COUNT(*) FROM wp_es_issues GROUP BY state;
SELECT COUNT(*) AS articles, SUM(public_json IS NOT NULL) AS public_articles FROM wp_es_articles;
SELECT MAX(number) FROM wp_es_issues;
SELECT name, value FROM wp_es_state WHERE name IN ('number', 'catalog');
SELECT option_name, option_value FROM wp_options WHERE option_name IN ('es_runtime', 'es_security', 'es_db_version');
-- только если до этого стояла 0.5.x (таблица есть):
SELECT layer, meta_key, COUNT(*) FROM wp_es_meta GROUP BY layer, meta_key;
```

Сохраните также 2–3 адреса опубликованных материалов (`/gazeta/material/...`) — после обновления они должны открываться так же.

## 2. Обновление 0.3.4 / 0.3.5 / 0.4.0 / 0.5.x → 0.5.4

1. «Газета → Режим»: убедитесь, что режим «Закрытый тест» (или «Остановлена»). Открывать газету читателям во время обновления не нужно.
2. «Плагины» → деактивируйте «Ежедневный стандарт». Данные остаются, режим при следующей активации — закрытый.
3. «Плагины → Добавить новый → Загрузить плагин» → `kozlov-jazzeta-0.5.4.zip` → «Заменить текущую версию загруженной».
4. Активируйте под учётной записью владельца газеты. Активация повторяет те же `CREATE TABLE` (dbDelta), создаёт недостающие таблицы — `wp_es_meta` (если её не было) и `wp_es_search` (указатель поиска) — и собирает указатель из опубликованных материалов. Ничего не удаляет, не переименовывает и не пересчитывает в прежних таблицах.
5. «Газета → Проверка данных»: сравните числа с шагом 1. Ошибок быть не должно. Строка «Поиск по газете» должна показать «В указателе N из N». «Внимание» по адресам `/gazeta/` или `/gazeta/search/` лечится пересохранением «Настройки → Постоянные ссылки» (ничего не меняя). Адреса `/gazeta/crossword/` появляются после того же «Завершить обновление» или пересохранения постоянных ссылок; до этого ссылки газеты ведут на запасной адрес с `?es_view=`, он работает.
6. Очистите кэш страниц для `/gazeta/*`.
7. Проверьте в браузере владельцем: `/gazeta/`, `/gazeta/<дата>/`, сохранённые адреса материалов, подшивку, предпросмотр черновика; ссылку «← На сайт Клуба Козлова»; кнопку «Оформление» и три вида на телефоне и компьютере; «Газета → Оформление → Предпросмотр трёх видов»; **«Поиск» в шапке: имя из опубликованного материала находится, в другой форме слова тоже**; **в карточке материала с фото — блок «Кадр»: щелчок по лицу, «Сохранить кадр», предпросмотр номера**; **в карточке выпуска — «Кроссворд недели»: загрузить `examples/crossword-example.json` (или свой файл), «Предпросмотр», решить пару слов на телефоне (касание клетки открывает клавиатуру газеты, системная не появляется), «Убрать кроссворд», если номер не должен его нести**; что главная, афиша и покупка билета работают как раньше.
8. Проверьте анонимно (окно инкогнито, другой браузер): в закрытом режиме `/gazeta/` отдаёт 404, страница не попадает из кэша.

Если пункт 3 сделан без деактивации, плагин увидит, что база записана старой версией: газета временно отдаёт 503, а в меню появляется «Газета: восстановление». Там нажмите «Завершить обновление» (нужны права администратора и отметка «Резервная копия базы сделана»). Это то же действие, что и активация.

Что 0.5.x добавляет в базу: таблицу `wp_es_meta` (пустую, пока редактор не заполнит обложку, блоки или кадр), таблицу `wp_es_search` (указатель поиска — производные данные, их можно удалить и собрать заново), строку `search` в `wp_es_state` и — только при сохранении «Оформления» — ключи `design` и `photo_mono` в `es_appearance` (как и 0.4.0: `typeface`, `design_version`, опцию `es_analytics`). Больше ничего нового не записывается.

Поиск: страницы `/gazeta/search/` попадают под исключение кэша `/gazeta/*` из п. 0.4 — отдельной настройки не нужно. Их нельзя кэшировать: в каждом ответе свой запрос.

Кэш: плагин по-прежнему запрещает кэшу WordPress хранить страницы газеты (`DONOTCACHEPAGE`). После публикации, снятия, смены режима и вида по умолчанию он просит сбросить только адреса газеты (W3 Total Cache — если установлен; другие слои — через действие `es_cache_purge_urls`). Исключения кэша до WordPress из п. 0.4 остаются обязательными.

## 3. Откат на прежнюю версию

Проверено на одной базе (эмуляция MySQL, см. `TEST-REPORT.md`): 0.3.4 и 0.3.5 читают и продолжают работать с данными, записанными 0.5.4 (публикация, номера, проверки материалов, черновики); выпущенные 0.4.0, 0.5.0, 0.5.1, 0.5.2 и 0.5.3 тоже. Таблицу `wp_es_search` 0.5.0 и старше не видят и не трогают (0.5.1–0.5.3 ведут её сами); `wp_es_meta` не видят 0.3.x и 0.4.0, а 0.5.0 и 0.5.1 сохраняют в ней незнакомые им кадр и кроссворд.

1. «Плагины» → деактивируйте 0.5.4 (режим станет закрытым, данные останутся).
2. Загрузите ZIP прежней версии с заменой и активируйте.
3. Очистите кэш `/gazeta/*`, проверьте выпуски и адреса.

Опция `es_analytics`, новые ключи оформления и таблицы `wp_es_meta`, `wp_es_search` при откате не мешают — прежняя версия их не читает. Удалять их не нужно: при возврате на 0.5.4 обложки, блоки, кадры и кроссворды окажутся на месте, а указатель поиска сам пересоберётся (он узнаёт, что старая версия публиковала или снимала выпуски). Пока стоит версия до 0.5.2, кроссвордов у читателей нет (адреса `/gazeta/crossword/` отдают 404); на 0.5.2 кроссворд есть, но на телефоне без клавиатуры газеты; на 0.5.0 нет и поиска; на 0.3.x и 0.4.0 читатели не видят обложку, блоки «Почему важно» и «Что известно» — только текст.

**Если админка не открывается:**
- создайте пустой файл `wp-content/plugins/kozlov-jazzeta/DISABLE-GAZETA` (без расширения) — модули газеты перестанут загружаться, режим станет «Остановлена», сайт клуба продолжит работать;
- если не помогло — переименуйте только папку `kozlov-jazzeta` в `kozlov-jazzeta.off`. Папку `plugins` целиком не трогайте.
Данные при этом не меняются. Возврат — только в закрытый режим, после устранения причины.

Восстанавливать всю базу из копии — крайняя мера: она откатит и заказы/билеты, оформленные после копии.

## 4. Режимы

| Режим | Кто видит газету | Правки и импорт |
|---|---|---|
| Закрытый тест (по умолчанию) | Только редакция (право es_edit) | Да |
| Открыта читателям | Все: только утверждённые выпуски | Да; читатели видят изменения после нового утверждения |
| Остановлена | Никто | Запрещены |

Открыть газету читателям может только выбранный владелец, из закрытого режима, с отметкой подтверждения. Открытие показывает **все** утверждённые выпуски — тестовые номера перед этим снимите.

## 5. Роли

- «Газета — редактор» (es_edit): правит материалы, подтверждает проверку, собирает номер. Не публикует.
- «Газета — импортёр» (es_import): только присылает черновики через REST с паролем приложения. Отдельный пользователь, не учётная запись владельца.
- Владелец (es_edit + es_publish, выбран в «Газета → Доступ»): публикует, снимает, открывает газету, заменяет черновик из JSON.
- Обычные роли WordPress («Редактор», «Автор») доступа к газете не получают.

## 6. Удаление плагина

Удаление через «Плагины» ничего не стирает из базы (как и в 0.3.x). Удаление данных — отдельное ручное решение.
