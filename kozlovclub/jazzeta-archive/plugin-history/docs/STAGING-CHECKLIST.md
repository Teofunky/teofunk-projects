# Приёмка на тестовой копии сайта клуба

Этот список выполняют на копии с реальной темой и плагинами. Он не заменяется локальными тестами пакета. Доступ к такой копии при разработке не предоставлялся. Автотесты `tests/` стирают свои таблицы и предназначены для отдельного пустого локального WordPress, а НЕ для этой копии.

## Подготовка

- [ ] Записаны версии WordPress, PHP, MySQL/MariaDB, темы, билетных/SEO/кэш-плагинов.
- [ ] Сделана и проверена резервная копия БД и файлов. Индексация копии закрыта; реальные письма, платежи, рассылки и исходящие интеграции отключены.
- [ ] Сохранены контрольные снимки главной, афиши, карточки события и оформления заказа; меню и настройки темы зафиксированы.
- [ ] Адрес /gazeta/ свободен. Внешний HTML-кэш/CDN исключает /gazeta/*; статика может кэшироваться.
- [ ] Отключена прежняя 0.2.0/0.3.0/0.3.1, загружен ZIP 0.3.4, плагин активирован владельцем. Нет PHP/SQL ошибок; появились только 10 собственных es_* таблиц и служебные настройки/права.
- [ ] В «Доступе» выбран правильный владелец. Созданы отдельные редактор и импортёр; сборщику не выдаются права администратора или сессия владельца.

## Редакция и публикация

- [ ] Создан черновик и/или импортирован examples/empty-draft.json: он не получает номер и не виден анонимно.
- [ ] Заполнены 4–7 реальных проверенных статей с одним главным материалом. Каждая редактируется отдельно, абзацы/курсив/списки/ссылки сохраняются.
- [ ] Проверены три уровня подтверждения, связь каждого факта с источником, независимость цепочек, цитаты и права на изображения. Непроверенная статья блокирует выпуск.
- [ ] Проверены предупреждения одинаковых URL/ID/текстов/event_id по прежнему опубликованному номеру. Для развития события указаны предыдущие материалы и существенный новый факт.
- [ ] Повторный импорт не создаёт номер; изменённый запрос без текущего If-Match отклоняется; импорт после ручной правки не перезаписывает редакцию.
- [ ] Две открытые формы: сохранение устаревшей формы получает конфликт, первая правка сохраняется.
- [ ] Предпросмотр доступен редактору, недоступен анонимному посетителю, содержит noindex и no-store.
- [ ] Редактор и импортёр не публикуют. Владелец после проверки предпросмотра явно подтверждает выпуск. Номер присваивается автоматически.
- [ ] В closed номер и все статьи открываются по своим URL только редакции. Для проверки публичного SEO на защищённой копии владелец отдельно переключает режим в public. В исходном HTML нет приватных заметок и неподтверждённых рабочих правок.
- [ ] Правка опубликованной новости остаётся рабочей и снимает прежнее подтверждение. Восстановление истории также не меняет публичный текст.
- [ ] Повторное утверждение обновляет текст без изменения номера/адресов. Снятие выпуска даёт 404 для него и статей, включая анонимный запрос через используемый кэш/CDN.

## Дизайн, SEO и совместимость

- [ ] Согласованы название, подзаголовок, девиз, локальный логотип и реальные ссылки «Афиша»/«Главная». Смена названия не меняет URL и статьи.
- [ ] Сверен приложенный классический макет: шапка, газетная сетка, цвета, типографика, подшивка, карточки.
- [ ] Проверены ширины 320/390/768/1440 px, длинные реальные заголовки, клавиатура, масштаб 200%, изображения разной формы и контраст выбранной палитры.
- [ ] Проверены настоящий Safari/iOS и Chrome/Android, ночной режим, размер текста, PNG 4:5 и копирование выжимки. Шрифты зависят от наличия Georgia/Times на устройстве; есть serif fallback.
- [ ] Газета читается без JavaScript. Основная тема, меню, афиша и билетный сценарий выглядят и работают как до установки.
- [ ] Canonical выпусков/статей, meta title/description, NewsArticle и Open Graph проверены на реальном домене; дубли метатегов отсутствуют.
- [ ] Проверена карта /gazeta/sitemap.xml. При blog_public=0 она закрыта. До открытия индексации копия должна оставаться недоступной поисковикам.
- [ ] На газете используется настоящая шапка/подвал темы; WPGlobus переводит меню, мобильная кнопка/поиск/календарь работают. В опубликованной версии штатные вставки темы не дублируются; в закрытом просмотре нет внешних сетевых запросов. CSS и ночной режим газеты не меняют шапку/подвал. Проверены title/canonical/robots без дублей.
- [ ] Архив проверен на реальном объёме данных с используемым object cache. После публикации новый номер появляется сразу.

## Отключение и решение о выпуске

- [ ] Деактивация отключает только маршруты газеты; тема, афиша, билеты и главная работают. Данные газеты остаются в БД.
- [ ] Повторная активация возвращает выпуски, историю, номера и настройки. Проверен возврат из резервной копии.
- [ ] Перенос 0.2.0 проверен на одном номере; исходный CPT и метаполя не изменились. Старые ссылки и номера согласованы отдельно.
- [ ] Зафиксированы оставшиеся дефекты и решение владельца. Установка на действующий сайт, меню и Beget — отдельные последующие действия.
