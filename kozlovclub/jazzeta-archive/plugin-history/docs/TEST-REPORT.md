# Проверка 0.3.4 — 21 октября 2026

Исправление подключения к теме. На действующем kozlovclub.ru подтверждена установленная версия 0.3.3 и ошибка языковых меток в самодельном меню. Для 0.3.4 прочитаны исходные header.php/footer.php/functions.php/style.css/js текущей темы через административный интерфейс. Рабочие файлы, меню и настройки сайта не изменялись. Версия 0.3.4 на сайт не установлена.

## Окружение и ограничения

WordPress 7.1.3, PHP 8.3.6, MariaDB 10.11.7, Chromium 156. На рабочем сайте ранее наблюдались WordPress 6.7.2, PHP 7.4.33, MySQL 5.7.21 и W3 Total Cache: полный этот стек локально не воспроизведён. Проверки WordPress 6.4 из предыдущих релизов не являются проверкой 0.3.4.

Фикстура использует неизменённые header.php, footer.php, style.css, js/script.js и библиотеки темы. В functions.php оставлены исходные функции подключения ресурсов и SEO; календарный endpoint заменён локальным JSON-фрагментом. Полная БД клуба, афиша, бронирование, билетный заказ, рабочий кэш и остальные плагины не копировались. Проверка календаря подтверждает открытие окна, а не актуальность концертных данных. В публичном тесте внешние запросы перехватывались; приватная страница блокирует их политикой CSP. В приватном режиме внешние шрифты/виджеты также не загружаются.

Исходники темы не входят в релиз: плагин использует активную тему сайта. Для тем без классических header.php/footer.php доступна газетная страница со ссылкой на главную, без имитации клубной шапки. Совместимость произвольных тем не заявляется.

Для установки: деактивировать газету, заменить ZIP, активировать 0.3.4. Материалы и настройки сохраняются, режим после активации закрытый. Финальная проверка на рабочем сайте выполняется после установки. Не запускать tests/ на рабочей БД.
