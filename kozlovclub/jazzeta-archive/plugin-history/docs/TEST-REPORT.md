# Отчёт о проверке — 0.5.0

Дата: 22.10.2026. Где: изолированная среда разработки (Linux), **не** сайт клуба и **не** его копия. Всё ниже — автоматические проверки без настоящего WordPress; это не замена приёмки на тестовой копии сайта.

## Что НЕ проверено и почему

- **PHP 7.4.33 и MySQL 5.7.21 в работе**, в том числе создание `wp_es_meta` через `dbDelta` и `INSERT … ON DUPLICATE KEY UPDATE` в MySQL. Нет в среде.
- **Настоящий WordPress 6.7 с темой, Yoast 21, W3 Total Cache и плагинами сайта**: медиатека в выборе обложки, предпросмотр трёх видов во фреймах (в тестовой сборке адрес предпросмотра ведёт на неработающий домен, фреймы пустые), сброс кэша W3TC, админ-панель WordPress поверх газеты.
- **Сайт клуба** — по условию ничего не устанавливалось и не менялось.
- **Полевые Core Web Vitals** (75-й перцентиль) — только с рабочего сайта; лабораторные цифры выше получены без темы, Yoast, хостинга и реальной сети.
- **Ручная доступность**: экранный диктор (VoiceOver, NVDA, TalkBack), увеличение 200 %, клавиатура в настоящем WordPress.
- **10+ материалов в номере**: формат JSON 1.1 допускает не больше 7; вёрстка номера из 10 проверена на синтетическом выпуске в обход лимита.

## Как повторить

Тесты и инструменты входят в пакет разработчика `kozlov-jazzeta-0.5.0-dev.zip`.

```sh
# без браузера
sh tests/run-all.sh <выпуск JSON 1.1> <распакованный плагин 0.3.4 или 0.3.5> [<распакованный 0.4.0>]

# с браузером: страницы и локальный HTTP-сервер
php tests/harness/render.php          <выпуск.json> <папка>/out   <URL папки плагина>
php tests/harness/render-variants.php <выпуск.json> <папка>/out   <URL папки плагина> <URL папки с тестовыми фото>
php tests/harness/render-admin.php    <выпуск.json> <папка>/admin <URL папки плагина>
sh tests/run-all.sh <выпуск.json> <0.3.x> <0.4.0> <URL папки>
SHOT_BASE=<URL папки>/out/ node tests/browser/a11y.js
SHOT_BASE=<URL папки>/out/ node tests/browser/perf.js
```

Тесты пишут только во временную базу SQLite и никогда не обращаются к сайту.

## Что нужно, чтобы закрыть оставшиеся риски

1. Тестовая копия сайта (Beget) с той же версией PHP, MySQL, WordPress, темой и плагинами — пройти `docs/UPGRADE-ROLLBACK.md` целиком, включая откат на 0.3.4.
2. На копии: выбрать обложку в медиатеке, заполнить блоки, опубликовать, проверить три вида на телефоне и компьютере, предпросмотр в «Оформлении», экранный диктор.
3. После запуска на сайте — данные Search Console / CrUX для полевых метрик.
