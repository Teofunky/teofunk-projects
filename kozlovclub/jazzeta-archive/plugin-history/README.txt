KOZLOV JAZZETA — 0.1.0 (ПИЛОТ)

ЧТО РАБОТАЕТ
- Изолированный тип публикации jz_issue, не вмешивается в шаблоны существующего сайта.
- Вставка JSON с проверкой обязательных полей, дат, https-ссылок, дублей и квот 2–3/3–4 (при коротком номере из 4 допустимо 2+2).
- Статусы demo и draft хранятся как черновики, approved публикуется только редактором.
- Внешний импорт через авторизованный REST /wp-json/kozlov-jazzeta/v1/import
- Публичное чтение последнего номера /wp-json/kozlov-jazzeta/v1/latest
- Газетный шорткод [kozlov_jazzeta], архив и пять соцсводок.

НЕ РЕАЛИЗОВАНО В ПИЛОТЕ
- Автоматический поиск и языковая переработка внешних новостей ИИ.
- Семантическая проверка достоверности каждого факта / реальная доступность внешней ссылки.
- Автоматический экспорт PNG-карточек с сервера и публикация в Telegram / Instagram.
- Планировщик ежедневного сбора новостей и фактчекинг без человека.
Эти этапы должен выполнять отдельный редакционный конвейер с журналом проверки.

УСТАНОВКА (СНАЧАЛА НА STAGING!)
1. Сделать резервную копию сайта и БД.
2. Загрузить zip в «Плагины → Добавить → Загрузить плагин» и активировать на staging.
3. Создать страницу «Джазета» с шорткодом [kozlov_jazzeta].
4. Зайти в «Джазета: выпуски → Импорт JSON», вставить sample JSON.
   Его статус demo: на публичной странице он НЕ ПОЯВИТСЯ.
5. Проверить верстку, контент, ссылки; для публикации в JSON сменить status на approved.
6. Только после тестов переносить на боевой сайт.

ПРИМЕЧАНИЕ
Никакой агент не может достоверно проверить публикацию только по значению verified:true:
этот флаг должен означать завершенную проверку редактором/контролем источников.
Не публикуйте полностью переведенные чужие статьи без необходимого разрешения.
