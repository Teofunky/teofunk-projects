ДЖАЗЕТА 0.2.0 — СИСТЕМА ЧЕРНОВИКОВ И РЕДАКЦИОННОЙ ПУБЛИКАЦИИ

ВАЖНО: это WordPress-плагин для хранения выпусков, проверки и публикации редактором.
Автономный ИИ-сбор материалов из внешнего интернета, генерация текста и
независимый фактчекинг пока НЕ реализованы. Входящий JSON готовит отдельный
редакционный конвейер. Не устанавливать на действующий сайт без staging.

ЧТО ИЗМЕНИЛОСЬ ПОСЛЕ 0.1.0
- Любой JSON с любым статусом импортируется ТОЛЬКО КАК ЧЕРНОВИК.
- Редакция / публикация: просмотр номеров, полный текст и источники, кнопка
  «Проверил номер — опубликовать выпуск» с проверкой nonce и прав.
- Обычные редакционные действия (Quick Edit, Bulk, штатный экран) не могут
  опубликовать новый черновик в обход одобрения.
- Все 30 предоставленных сайтов внесены в sources.json и «Каталог источников»:
  17 международных, 8 российских, 5 лейблов.
- Защита от перезаписи опубликованного выпуска при повторном импорте.
- Для номера из 4 материалов допускаются 4 социальные карточки, для 5-7 — пять.

КАК ПРОВЕРИТЬ НА STAGING
1. Бэкап файлов и БД, проверить совместимость PHP и плагинов на копии сайта.
2. Плагины -> Добавить -> Загрузить плагин -> активировать 0.2.0.
3. Создать отдельную страницу с шорткодом [kozlov_jazzeta].
4. Джазета: выпуски -> Импорт JSON, вставить sample JSON (он остается черновиком).
5. Джазета: выпуски -> Редакция / публикация, проверить каждую новость и ссылки.
6. Нажать «Проверил номер — опубликовать выпуск».
7. На странице с шорткодом отображается свежий выпуск и архив старых номеров.

ИНТЕГРАЦИЯ
- Защищённая загрузка черновика: POST /wp-json/kozlov-jazzeta/v1/import
  Доступ: редактор с правом edit_others_posts, с WordPress Application Password
  или авторизованной cookie + REST nonce.
- Только чтение опубликованного номера: GET /wp-json/kozlov-jazzeta/v1/latest
- Источники: sources.json. Приоритет A/B/C и пометки, НЕ подтверждение RSS.
- Перенести источник как ссылку на публикацию можно только после проверки
  URL, даты и корректности фактов. Сам флаг verified:true недостаточен.

НЕ ГОТОВО К ПРОДАКШН-АВТОМАТИЗАЦИИ
- Парсеры RSS/API и RSS-discovery для каждого сайта.
- Ежедневный cron и LLM редактор, который формирует свежий JSON.
- Независимая верификация содержания, прав на фото и прямых цитат.
- Отправка и графический экспорт в Telegram/Instagram.
- Интеграционные тесты с конкретным сервером козловclub.ru и темой сайта.

Из переданного перечня: 30 уникальных URL, а не заявленные 34.
Оставшиеся 4 адреса не придуманы и не добавлены.
