- Is making a new site to replace jazzartclub.ru, carrying over all existing texts, menu items and rubrics
- Main audience is 60+ and views from desktop computers
- Wants it modern, simple, stylish, with large fonts and typography, easy editing and adding of articles
- Going with WordPress for the new site; the old site is also on WordPress
- Chose to hand over content as an export from the old site's admin
- Prefers the images folder to stay on the server rather than be downloaded and re-uploaded
- Wants the old site's logo and colours kept in the new design
- Priority is a simple migration where everything works at once and is intuitive for 60+ visitors
- Wants classic, readable, slightly Soviet newspaper-style typography (like Известия or Правда), possibly all caps for menu items and rubrics; disliked the earlier fonts
- Menu items must not wrap into several rows
- Plans to launch it as a test on some hosting first, with images attached and links working
- Test copy of the new site is running at www.teofunk.ru
