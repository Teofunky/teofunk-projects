- Building Reel Practice: an app that turns guitar Reels he saves from Instagram into a structured library of lessons with TABs, tags and practice tools
- Mac build reached version 2.5 — FastAPI backend plus an AppleScript launcher, library data kept in ~/Library/Application Support/Reel Practice
- Plans a native iOS version with an Instagram Share Extension and an iPhone → Mac processing queue over CloudKit
- Core product rule: never invent TAB, key, chords or tags the source video doesn't support
- Playback speed control is deliberately excluded from the concept
- Saves guitar Reels from Instagram regularly; organising that backlog is the whole point of the project (relates to [[guitar-learning]])
