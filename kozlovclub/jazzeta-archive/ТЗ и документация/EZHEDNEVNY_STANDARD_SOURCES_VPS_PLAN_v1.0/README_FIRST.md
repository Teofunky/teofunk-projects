## Начать с файла `ENGINEERING_AND_VPS_PLAN.md`

- `sources-registry-v1.json` — машинный реестр, все каналы выключены.
- `SOURCES_README.md` — удобный список с URL, категорией и статусом проверки.
- `sources-original-30.json` — 30 исходных адресов пользователя без изменения.
- `ENGINEERING_AND_VPS_PLAN.md` — план отдельного VPS и требования к сборщику Claude.

ПЕРВОЕ действие владельца в Beget Cloud: открыть https://cp.beget.com/cloud/create, выбрать *новый* виртуальный сервер Ubuntu 24.04 отдельно от сервера «Виджет на сайт»/«Джаз Навигатор», проверить цену и создать сервер. Это изменение ещё не выполнено.

Рекомендуемые параметры: 2 vCPU / 2 ГБ RAM / 25–30 ГБ SSD (настройка приблизительная; использовать ближайшую конфигурацию Beget), публичный IPv4, SSH-ключ и бэкапы.

## Термины статуса
- `site_page_confirmed_not_feed`: найден сайт/страница через веб-поиск; RSS и права не проверены.
- `in_original_30_not_validated`: из утверждённых пользовательских 30 без доп. проверки.
- `candidate_requires_verification`: редакционный кандидат, точный URL/доступность не гарантированы.
- `community_confirmed_api_disabled`: обсуждение в сообществе найдено, но автоматический API запрещён до проверки прав.

Не смешивать количество **редакционных точек наблюдения** с количеством **уникальных СМИ**: один издатель может быть в нескольких группах (сайт, YouTube, Telegram).
