# Календарь «Этот день в джазе» для Ежедневной Джазеты

## Запуск (Терминал на Mac, в этой папке)
```
python3 jazz_calendar.py build                      # база -> data/people.json, data/review.csv (около минуты)
python3 jazz_calendar.py export                     # data/calendar.json: с 21.10.2026 примерно на 14 месяцев вперёд
```
Затем на сайте: «Газета → Календарь» → загрузить `data/calendar.json` (только владелец газеты).
Обновлять раз в месяц или после правок в manual*.json / overrides.json / extra_people.json.

Проверка без сайта:
```
python3 jazz_calendar.py pick --date 2026-11-10 --preview   # рубрика на день текстом
python3 jazz_calendar.py pick --days 7 --preview            # неделя вперёд
```

## Откуда данные
- Мир: Wikidata, люди с джазовой профессией и не менее 12 статей в Википедиях.
- Россия: категории «Джазмены России/СССР» и др. в ру-Википедии, плюс джазмены с гражданством России, СССР, Российской империи (без порога известности).
- `extra_people.json`: свой список российских музыкантов, которых нет в категориях (QID из Wikidata).
- `manual.json`: даты клуба и люди без статьи в Wikidata. Попадают в выпуск первыми, только с `"verified": true`.
- `overrides.json`: исключить человека, задать русское имя, подпись профессии или выбрать дату при споре.

## Правила
- Даты только с точностью до дня. Устаревшие (deprecated) утверждения Wikidata отброшены.
- Если у человека несколько разных дат, запись не публикуется, пока вы не выберете дату в `overrides.json`.
- Старый стиль Wikidata отдаёт уже пересчитанным на новый (проверено на Парнахе и Энтелисе).
- Строки собираются шаблоном «N лет со дня рождения/смерти: Имя, профессия»: без склонения имён и глаголов с родом.
- Отбор: до 4 записей, сначала ручной слой, минимум 1 российская (если есть), потом по известности и круглым датам.

## Пример правки overrides.json
```
"Q487043": {"name_ru": "Эллис Марсалис"},
"Q124769996": {"occupation_ru": "певец"},
"Q1382411": {"death": "1998-11-12"}
```
